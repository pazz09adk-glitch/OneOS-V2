# 业财闭环 · 总览导航 PRD

| 项 | 内容 |
|---|---|
| 原型 | `/prototypes/biz-finance-closed-loop` |
| 基准 | `foundations/biz-finance-integration` · 汇报稿 |
| 置信度 | architecture |

## 1. 目标

为领导汇报与产品推进提供**一条入口**：讲清业财公式、七条链、原型跳转；讲演用页见「业财闭环汇报」`/prototypes/biz-finance-line-briefing`。

## 2. 用户故事

| 角色 | 起点 → 运作 → 闭环 |
|------|-------------------|
| 产品/业管 | 打开总览 → 按模块卡片进入对应原型 → 对照门禁验收 |
| 财务总 | 看收付款对照与纪律 → 点进收付款中枢看关联演示 |

## 3. 范围

- **做**：导航、公式、模块状态、跳转已有/新建原型  
- **不做**：在本页内实现全部业务表单（拆多会话）

## 4. 验收

1. 侧栏可见「业财闭环」  
2. 点击「收付款关联」「客户风险」可打开对应新页  
3. 签约/账单/还车跳到既有 V2 原型  
4. 待建模块不可误跳空页
