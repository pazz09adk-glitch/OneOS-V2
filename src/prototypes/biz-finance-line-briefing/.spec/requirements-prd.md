# 业财闭环汇报 · PRD

| 项 | 内容 |
|---|---|
| 原型 | `/prototypes/biz-finance-line-briefing` |
| 基准 | 汇报稿 · `foundations/biz-finance-integration` · 业务条线说明页交互母版 |
| 置信度 | architecture |

## 1. 目标

给业务管理组主管、分管领导、财务部总经理一份**可投影、可滚动、可跳原型**的汇报页：讲清业财公式、谁干什么、七条链「起点→运作→闭环」、收付对照、门禁与待拍板。

## 2. 用户故事

| 角色 | 起点 → 运作 → 闭环 |
|------|-------------------|
| 汇报人 | 打开汇报页 → 演示模式逐步翻模块 / 点侧栏跳章节 → 链到 bfcl 原型验门禁 |
| 听众（业管/财务总） | 看公式与纪律 → 对收付表 → 记下四项拍板 |

## 3. 范围

- **做**：暗色讲演页、响应式、scroll-spy、演示步进、七链+财务中枢模块卡、收付对照、门禁、拍板、跳转业财原型族  
- **不做**：在本页内做业务表单；不拆侧栏多级页

## 4. 验收

1. 侧栏可见「业财闭环汇报」  
2. PC / 窄屏可滚读；演示模式可上一/下一模块  
3. 各模块「打开业财·××」跳到对应 `/prototypes/bfcl-*`  
4. 总览 Hub 可进入本汇报页
