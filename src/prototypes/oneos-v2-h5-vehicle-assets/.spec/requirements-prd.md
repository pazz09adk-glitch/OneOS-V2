# 车辆资产 H5 移动端 (微信小程序 / 小羚羚 App 嵌套) · 产品需求说明 (PRD)

## 1. 模块定位与基准

| 项 | 说明 |
|---|---|
| 模块名称 | 车辆资产 H5 移动端 (Vehicle Assets H5) |
| 适配场景 | **微信小程序嵌入** · **小羚羚 App Webview** · **手机浏览器** |
| 设计规范 | **OneOS V2 全局定版设计规范** (Stripe Violet `#533AFD`) |
| 视口兼容 | **iPhone 15 (390px)** · **Android (375px)** · **PC 全宽响应式** |
| 触控规格 | 触控热区 **`≥ 44px`**，内文字号 **`≥ 14px`**，Bottom Sheet 吸底抽屉 |
| 三视角架构 | **1. 列表模式 (List Card)** · **2. 看板模式 (Kanban Pipeline)** · **3. 档案工作台 (Split Workbench)** |
| 数据口径 | 实时同步 PC 车辆资产台账 (`vehicles.json`) |

---

## 2. 三视角 H5 交互与功能规则

1. **列表模式 (List View)**：
   - 顶部 4 卡片 Bento KPI 网格（全部车辆、已交车、待交车、预警/出险），支持点击直达筛选；
   - 快捷搜索框（搜车牌/VIN/客户）+ 13 项高阶条件 Bottom Sheet 抽屉；点击 **确认查询 / 重置** 后**关闭 Drawer** 并按条件展示结果（OneOS V2 查询收起规则）；
   - 车辆卡片列表：Stripe 紫车牌号（无点标准，形如 `粤AGP3673`）、状态胶囊 Pill、实时里程 (`tabular-nums`)、归属地与折叠式**车辆关联履约/保单/违章子明细**；
   - 支持多页码触控分页控制器 (`V2Pagination`)。
2. **看板模式 (Kanban View)**：
   - 4 阶段 Pipeline 管道（库存待交车、履约执行中、维保/出险中、退车/结清中）；
   - H5 管道列横向滑动切 Tab；支持快捷【更新里程】与【发起处置/出险】。
3. **档案工作台模式 (Split View)**：
   - 顶部车辆快捷搜索与卡片轮播选择；
   - 5 大深度档案 Sub-tabs：基础档案、履约合同、证照年检、保险保单、出险违章；
   - 固定吸底操作条 (`V2MobileActionBar`)，带有安全区 `env(safe-area-inset-bottom)` 护航。
