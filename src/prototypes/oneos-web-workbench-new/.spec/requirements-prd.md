# 工作台 (V2) · 产品需求说明 (PRD)

> **页面类型**：OneOS V2 全局定版规范原型  
> **设计标准**：`src/resources/design-system/DESIGN.md`  
> **能力归属**：运营看板的「角色绑定部门」由若依用户中心 · 角色管理维护；本原型用 `RoleConfig.boundDeptId` 模拟绑定结果。

---

## 1. 目标与范围

- **一屏开工**：登录后按角色展示快捷入口、预警、运营看板、待办与审批；
- **快捷入口自定义**：快速发起 + 功能入口，支持钉选编辑，按角色记忆；
- **预警密集展示**：按功能模块分组的高密指标条（十余项可读）；
- **部门运营看板**：角色绑定部门后共用该部门看板模板；多角色用 Tab 切角色；
- **待办排序**：逾期优先，其次创建时间倒序；支持紧急程度 / 业务类型筛选；主管多通道催办；
- **审批中心**：待办 / 我发起的 / 已办 / 抄送；展示发起时间、停留、进展；抄送显示抄送内容；发起人可催办。

---

## 2. 页面架构

1. **欢迎区**：问候、模拟角色；右上角「常用快捷入口」展开 +「自定义」编辑；
2. **预警中心**：模块分组折叠，组内紧凑指标行，点击开明细；
3. **运营看板**：Tab=角色（多角色时）；内容=`boundDeptId → 部门模板`（业管三列 / 运维四列 / 财务双列 / 通用）；
4. **我的待办** + **审批中心**双栏；
5. **通知 / 版本更新**：工作台内不展示入口，走「原型外壳演示」顶栏。

---

## 3. 关键规则

### 角色绑定部门 → 看板

- 同一部门可挂多个角色（如业管 / 能源组 / 业务部均可绑 `biz`）；
- 切角色 Tab 时读取该角色绑定部门，渲染对应部门看板；绑同部门则内容一致；
- 未绑定部门：空态提示前往角色管理绑定。

### 待办排序

1. `urgentLevel=overdue` 优先；
2. 同优先级按 `createTime` 倒序。

### 催办

- 通道：邮件 / 短信 / 微信（分享链接），多选且至少 1 项；
- 待办：部门主管且任务允许催办；
- 审批：`我发起的` 且 `initiatorCanUrge`。
