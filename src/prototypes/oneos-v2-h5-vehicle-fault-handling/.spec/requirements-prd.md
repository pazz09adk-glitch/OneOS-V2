## 2. 三视角 H5 交互与功能规则

### 2.1 列表模式 (List View)

- 顶部 4 卡 Bento KPI：**全量** / **待处理+处理中** / **挂起** / **临期逾期**，点击直达筛选；
- 快捷搜索：车牌号、故障单号；
- 高阶筛选 Bottom Sheet：**故障部位**、**故障等级**、**解决情况**、**运维负责人**；
- 卡片列表：车牌（无 `·`）、等级 Tag、任务状态 Badge、处置时限 Tag、负责人；
- 点击卡片进入 **处置工作台 (Split)** 或详情面板；
- 列表分页 `V2Pagination`。

### 2.2 看板模式 (Kanban View)

- 4 列 Pipeline：`pending` / `processing` / `suspended` / `archived`；
- H5 横向 Tab 切列，列内卡片展示车牌、等级、处置时限、负责人；
- 卡片快捷进入处置工作台。

### 2.3 处置工作台 (Split View)

- 顶部单据快捷选择条；
- 详情区：故障描述、AI 排查摘要、处置结果、附件数量；
- 挂起记录摘要、催办通知摘要 Timeline；
- 吸底操作条：**处置**、**挂起**（非归档态）、**催办**；
- Toast 反馈操作结果（原型模拟）。

## 3. 处置时限 / 挂起 / 归档 / 催办（与 PC 对齐）

| 能力 | H5 规则 |
|---|---|
| **30 天处置时限** | 上报日 +30 天为截止日；Caption 辅文展示（不用标签）；**临期≤7 预警色、已逾期警告色**，其余 muted；已挂起显示「挂起、暂停中」且不计时限，不进临期/逾期 KPI |
| **挂起** | 处理中/待处理可挂起；必填挂起分类与原因；留痕于 `suspendHistory`；挂起期间暂停时限计算 |
| **归档** | 已解决 + 证据链附件完备方可归档（H5 原型 Toast 模拟门槛校验） |
| **催办** | 临期/逾期可发送短信/邮件/系统催办；留痕于 `notificationHistory` |
