# 列表 · 车牌 / 车辆识别代码

## 起点 → 运作 → 闭环

- **起点**：台账冻结列「车牌 / 车辆识别代码」
- **怎么运作**：
  1. **第 1 行**：车牌号（主色下划线）+「查看 ›」引导，后方跟车辆状态 Tag
  2. 点击车牌号或「查看」进入页内车辆档案详情
  3. **第 2 行**：车辆识别代码（等宽数字，辅文色）
- **闭环**：打开目标车辆档案，或确认车牌 / 识别代码后继续筛查

## 展示规则

| 行 | 内容 | 说明 |
|----|------|------|
| 第 1 行 | 车牌号 + 查看引导 + 车辆状态 | 车牌为进详情主入口；状态 Tag 紧随其后 |
| 第 2 行 | 车辆识别代码 | 导入主键必填，正常必有值；异常缺漏时留空，**不**展示「—」 |

部分车辆状态附「暂未上线」提示。**悬停状态 Tag** 可看该状态定义（与专题规则表一致）。

## 约束

- 本列为左冻结列之一，横向滚动时始终可见
- 列表操作列不再单独外显「查看」按钮；进详情以本列车牌入口为主（⋯ 菜单仍保留「查看详情」）
