# 车辆状态标签规则

列表 / 详情车牌旁展示车辆状态 Tag。部分状态附「暂未上线」。**悬停 Tag** 展示该状态含义（对齐下方规则表）；本标注汇总全量规则（对齐状态说明图）。

![车辆状态规则图](/prototypes/vehicle-management/assets/vehicle-status-rules.png)

## 已上线状态

| 状态 | 规则 |
|------|------|
| 未备车 | 尚未备车，可随时发起备车 |
| 已备车 | 已完成备车并在备车库中，可随时交车（须证照 / 保险正常、运营状态允许） |
| 待交车 | 租赁合同已确定车牌，签约后占位，防止被其他业务误交 |
| 已交车 | 运维 E 签宝交车签章完成即算已交车，无需等待客户签章；此时运营状态必为租赁或自营 |
| 待还车 | 还车任务已生成，还车流程尚未完成 |
| 报废中 | 报废流程已审批通过，尚未完成报废情况填写 |
| 替换中 | 替换车流程通过后新车标记；完成后新车为已交车。旧车：永久替换则还车后未备车，临时替换仍已交车 |
| 调拨中 | 调拨流程通过后标记；接收人完成接车后恢复调拨前状态 |
| 异动中 | 异动流程通过后标记；操作人完成异动结束后恢复异动前状态 |
| 无 | 报废 / 销售 / 三方退租完成后的终态，不再参与在库运营占位 |

## 暂未上线状态

以下状态展示 Tag，并附「暂未上线」：

| 状态 | 规则 |
|------|------|
| 待验车 | 采购 / 三方租用入库后尚未完成验车 |
| 呆滞车 | 将随呆滞车管理功能上线 |
| 维修中 | 维修单未完成或未标记已修复；修复后恢复维修前车辆状态 |
| 过户中 | 内部过户进行中，尚未完成信息填写与证件更新 |
| 销售中 | 销售流程已通过，尚未完成销售结果填写；完成后车辆状态为无、出库为销售出库 |
| 三方退租中 | 三方退租已通过，尚未完成退租确认 |
