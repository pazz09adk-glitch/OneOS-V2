# 列表 · 合同 / 项目（合同编号跳转）

## 起点 → 运作 → 闭环

- **起点**：台账「合同 / 项目」列，第 1 行合同编号
- **怎么运作**：
  1. 有合同时：合同编号主色下划线 +「查看 ›」引导（与车牌入口同级）
  2. 点击合同编号或「查看」→ **新标签页**打开租赁合同详情（主从视图）
  3. 第 2 行展示项目名称（只读，不跳转）
- **闭环**：在新标签核对合同详情后，可关闭标签回到车辆台账继续查车

## 展示规则

| 行 | 内容 | 说明 |
|----|------|------|
| 第 1 行 | 合同编号 + 查看引导 | 无合同时「未关联合同」 |
| 第 2 行 | 项目名称 | 无项目时「未关联项目」 |

空态：未关联合同与项目时展示「未关联合同 / 无履约项目」空卡。

## 原型与正式环境

| 环境 | 行为 |
|------|------|
| 原型 | 新标签打开 `/prototypes/lease-contract-management?contractCode=…&view=split`；无同号种子时用桥接详情演示编号 |
| 正式环境 | 新标签进入租赁合同详情页，按合同编号定位真实单据 |

## 约束

- 仅合同编号可点；项目名称不可点
- 不打断当前车辆列表筛选 / 分页状态（新标签打开）
