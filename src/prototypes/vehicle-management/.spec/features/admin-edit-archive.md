# 专题 · 编辑档案权限（Admin 兜底）

> **给开发与测试的着重说明**：本能力是**正式环境权限规则**，不是要求在原型页面上做「角色切换」或「假登录」。

## 产品规则（必须按此实现）

- 「编辑档案」**仅超级管理员（Admin）**可见、可用。  
- 普通运维、车辆管理人员**禁止**直接修改车辆状态及档案兜底字段。  
- 车辆状态与多数台账数据由交还车 / 调拨 / 维保等**独立业务线闭环**驱动并留痕。  
- Admin 编辑仅用于**资产数据异常时的兜底纠正**，不替代业务线。

## 原型边界（避免误判）

| 不要误解 | 正确理解 |
|----------|----------|
| 原型里能点「编辑档案」= 全员都有权限 | 原型只为演示弹层路径；**正式环境必须按角色显隐** |
| 评审说缺 Admin 门禁 = 要在页面加「切到 Admin」 | **禁止**页内角色切换器；用登录权限接口 |
| 照抄原型交互即可过验收 | 验收看**权限接口 + 非 Admin 不可进入** |

## 正式环境验收要点

- [ ] Admin 登录：⋯ 中可见「编辑档案」，可保存兜底修改并留痕  
- [ ] 非 Admin：⋯ 中**无**「编辑档案」，直链 / 接口亦不可改  
- [ ] 无页面级「当前角色：Admin/运维」切换控件  

## 与操作列关系

操作列仅为 ⋯；菜单顺序：查看详情 → 设置运维负责人 → 编辑档案（最后一项，且受 Admin 控制）。
