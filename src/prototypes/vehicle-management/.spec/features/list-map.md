# 列表 · 车辆定位地图

## 起点 → 运作 → 闭环

- **起点**：列表「运营城市」列点击省-市（**仅车机 / GPS 来源**；人工不可点开地图）
- **怎么运作**：打开地图弹层；车辆始终居中；支持放大缩小；在线绿点 / 离线灰点；在线移动时定时拉取 GPS 最新位置并跟车
- **闭环**：关闭弹层回到列表

## 准入

| 城市来源 | 可否打开地图 |
|----------|--------------|
| 车机 | 可（有坐标时） |
| GPS | 可（有坐标时） |
| 人工 | **不可**（未接入定位，仅可改运营城市） |

## 地图规则

| 项 | 口径 |
|----|------|
| 定位点颜色 | **在线 = 绿色**；**离线 = 灰色**（末次上报，非实时） |
| 居中 | 该车始终显示在地图中心 |
| 缩放 | 支持放大 / 缩小 |
| 移动跟车 | 车辆在线移动时，定时经 GPS 接口取最新位置，地图位置持续更新且保持居中 |
| 详细地址 | 列表不展示；在地图弹层查看 |

## 列表展示

- 车机 / GPS：省市可点 + 地图针
- 人工：省市导向运营城市维护，不打开地图
