# 列表 · 保险列

> 标注点：`va-feat-list-insurance`（表头「保险」）

## 用户故事

- **起点**：在车辆台账扫读保险是否可交车、是否需续保
- **怎么运作**：上行看总览状态；交强险、商业险各占一行扫读到期与色标
- **闭环**：异常或临期车辆可进详情 / 采购演示链路关注续保

## 列结构（三行）

| 行 | 内容 |
|----|------|
| 第 1 行 | **保险状态**标签：正常 / 临期 / 异常（带图标；悬停可看具体险种说明） |
| 第 2 行 | **交强**：标签名 + 到期日；临期 / 已过期时追加「剩余 / 已过期 N 天」色标 |
| 第 3 行 | **商业**：同上，独立一行（不与交强并排） |

字体与左侧「证照」列对齐：标签名 10px/700；日期 12px/500 等宽数字；剩余天数右对齐。

点击交强 / 商业行可演示跳转保险采购。

## 保险状态规则（总览）

按交强险、商业险两条到期日综合判定（优先异常）：

| 状态 | 判定规则 |
|------|----------|
| **异常** | 交强或商业任一**未购买**，或任一**已过期**；或档案标记为异常 |
| **临期** | 非异常前提下，交强或商业任一到期日在 **30 天内**（含当日） |
| **正常** | 交强与商业均在保，且均不在 30 天临期窗口内 |

说明：

- **临期不阻断交车**，仅提示采购 / 运维关注续保。
- 未购买在对应险种行展示为「未购买」，总览计入异常。

## 单险种行 · 日期色标（与证照列一致）

| 状态 | 日期 / 剩余文案颜色 | 展示 |
|------|---------------------|------|
| 有效（距到期 > 30 天） | 次要色（muted） | 到期日 |
| **临期**（≤ 30 天） | **预警色**（warning） | 到期日 +「剩余 N 天」 |
| **已过期** | **危险色**（error） | 到期日 +「已过期 N 天」 |
| 未购买 | **危险色**（error） | 「未购买」 |
