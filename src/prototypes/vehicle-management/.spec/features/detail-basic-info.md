# 详情 · 车辆基本信息

## 字段顺序

识别 → 归属 → 停放 → 来源资产 → 入库档案。

**默认两行（三列）**：车牌号（后随车辆状态标签）、品牌车型（主文 +「查看」）、车辆识别代码；登记所有权、运营公司、停放区域（在库有场站时字段名切换为「停车场」或「维修站」，取值场站名称）。

**展开后**：车辆来源、租赁公司；出厂年份 / 采购入库日期（可弹窗维护）；强制报废日期（只读，可带剩余 / 临期提示）。不单独再列「停车场」字段。

## 空值与维护

- 出厂年份 / 采购入库未维护：展示「暂未维护 · 去补充」
- 弹窗：年份选择器 / 日期选择器 → 保存 Toast；取消不改
- 其余档案兜底修改走列表「编辑档案」（仅 Admin）

## 其它

- 运营状态在卡片标题旁胶囊展示，不进字段栅格
- 运营城市 / 在线 / 定位时间不在此重复（见定位侧栏）
- 底部保留交车合规摘要（证照 / 保险 / 等评临期与过期一句话）
- 停放展示细则见专题「停放区域（停车场 / 维修站）」
