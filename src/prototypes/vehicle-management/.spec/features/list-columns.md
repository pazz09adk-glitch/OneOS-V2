# 列表 · 台账列与列设置

## 列顺序（产品口径）

品牌型号 → 车牌 / 车辆识别代码（含车辆状态标签）→ 运营城市 → 运营状态 / 客户 → 合同 / 项目 → 业务部门 / 经理 → 停放区域 → 登记所有权 → 车辆来源 → 证照 → 保险 → 里程 → 车辆里程考核任务 → 当前运维负责人 → 操作。

左两列冻结；操作列右冻结。

## 关键展示

| 列 | 要点 |
|----|------|
| 车牌 / 车辆识别代码 | 第 1 行：车牌号（引导「查看」）+ 车辆状态 Tag；第 2 行：车辆识别代码；部分状态附「暂未上线」 |
| 运营状态 / 客户 | 上方：运营状态标签；下方：当前租赁 / 物流合同客户名称（无则「在库未出租」） |
| 合同 / 项目 | 第 1 行：合同编号（主色下划线 +「查看 ›」）点击新标签打开合同详情；第 2 行：项目名称只读 |
| 业务部门 / 经理 | 取自租赁 / 物流合同：第 1 行业务经理，第 2 行业务部门；无合同时空卡 |
| 停放区域 | 判定序：调拨中 / 异动中 → 非库存运营状态 → 有无场站；有值时主文场站名、辅行停车场/维修站；缺失警示；未在库空卡 |
| 登记所有权 | 展示权属公司名称；**目前通过导入写入**；无值「未录入」 |
| 车辆来源 | 主行自有 / 外租 / 挂靠；辅行：自有固定说明，外租 / 挂靠展示来源公司 |
| 证照 | 第 1 行状态；第 2 行「行驶证」+ 到期日；非沪牌同行挂剩余天数；**沪牌特例**：状态与剩余天数均按等级评定时间（不以行驶证检验有效期） |
| 保险 | 第 1 行状态；第 2 行交强、第 3 行商业（各含到期日；临期/已过期追加剩余色标）；字体对齐证照列 |
| 运营城市 | 车机/GPS 可点开地图：在线绿点、离线灰点，车辆居中可缩放，在线移动定时 GPS 跟车；人工不可地图、可改城市 |
| 里程考核 | 政策补贴考核 ≠ 合同考核。剩余 = 目标 −（当前 − 工单初始）；初始默认车机→GPS→人工。预计天数 = 剩余 ÷ 近 7 活跃日均。预判：少于剩余→无法完成；裕量≤200→有风险；＞200→可完成 |
| 运维负责人 | 对应用户区域，命中最后交车/停车场/维修站省市。**查**：全运维可读全部车辆与运维业务；**写**：仅该车负责人可待办与操作（年审/调拨/异动/交还车/替换等） |

## 列设置

显隐、中间列拖拽调序、恢复默认（含列宽）。冻结列不可隐藏 / 拖离。  
用户账户持久化为正式环境能力；原型会话内生效即可。

## 操作列（§3.16）

外侧固定：**查看详情** → **设置运维**；低频 **编辑档案** 收入 ⋮。  

**【开发必读】「编辑档案」正式环境仅 Admin 可见**；原型可能仍展示菜单项以便演示弹层，**禁止**据此实现为全员可编辑，也**禁止**在页面上做角色切换器。详见专题 `admin-edit-archive.md` 与全模块 PRD §6.9。
