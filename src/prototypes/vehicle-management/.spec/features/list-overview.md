# 列表台账 · 总览

## 目标

提供车辆资产唯一入口下的列表工作台：在租结构感知、分类扫读、筛选查车、进详情。

## 起点 → 运作 → 闭环

- **起点**：侧栏打开「车辆资产」
- **怎么运作**：
  1. 上方查看在租车型占比
  2. 分类 Pill + 车牌 / 更多筛选缩小范围
  3. 台账分页浏览；点车牌进页内详情
- **闭环**：定位到目标车或确认当前条件下无车，返回筛选继续查

## 页面分区

| 分区 | 说明 |
|------|------|
| 在租车型占比 | 在租 TOP3；无业务线 Tab；可查看全部 |
| 工具条 | 分类 Pill、车牌主筛选、更多筛选、导出、导入、列设置 |
| 台账表 | 冻结列 + 业务列 + 操作 |
| 分页 | 默认每页 10，可选 10 / 20 / 50 / 100 |

## 不做

看板 / 主从切换；侧栏下级「列表页」路由。
