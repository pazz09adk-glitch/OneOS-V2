# 列表 · 运营城市列（定位 / 来源特殊规则）

## 起点 → 运作 → 闭环

- **起点**：台账「运营城市」列
- **怎么运作**：按城市来源（车机 / GPS / 人工）决定能否看地图、能否改城市
- **闭环**：查看定位地图，或完成人工运营城市维护

---

## 三类来源对照（特殊逻辑总表）

| 来源 | 省市点击 | 地图定位 | 辅行引导 | 能否改城市 |
|------|----------|----------|----------|------------|
| **车机** | 打开地图 | 有（在线绿点 / 离线灰点） | 「来源·车机」（不可改） | 否 |
| **GPS** | 打开地图 | 有（在线绿点 / 离线灰点） | 「来源·GPS」（不可改） | 否 |
| **人工** | **不打开地图**；可点省市进入修改 | **无**（未接入车机 / GPS） | 「来源·人工」+「修改 ›」 | **是** |

---

## 人工来源特殊规则（必读）

1. **没有接入车机和 GPS**，系统拿不到真实定位点  
2. **禁止**通过点击省市获取 / 打开定位地图（即使样例数据里带有城市基准坐标，也不应当作定位结果）  
3. 省市与「来源·人工 / 修改」均导向**运营城市维护**，不是地图  
4. 在线状态点展示为「未接入车机 / GPS」，不按车机在线 / 离线理解  
5. 未做过人工修改时，时间辅文为「暂无时间」；**人工修改运营城市并保存后**，以本次修改时间作为更新时间（列表显示「更新 …」，悬停「人工修改时间 …」）

---

## 车机 / GPS 地图规则

- 列表不直接展示详细地址；详细地址在地图弹层中查看  
- **在线**：绿色定位点；车辆移动时定时 GPS 刷新，点位跟车且始终居中，可缩放  
- **离线**：灰色定位点 = 末次位置，非实时  
- 仅来源为车机或 GPS 且可解析坐标时，省市旁显示地图针并可点击  

---

## 与详情侧栏一致

详情「定位信息」优先级：车机 → GPS → 人工。  
人工态说明未接入，并允许维护运营城市。
