# 列表 · 证照

## 起点 → 运作 → 闭环

- **起点**：台账「证照」列
- **怎么运作**：展示证照状态与到期扫读；沪牌额外展示等级评定，并走**沪牌特例规则**
- **闭环**：识别正常 / 异常与临期车辆，可进详情查看证照情况

## 展示结构

| 行 | 非沪牌 | 沪牌 |
|----|--------|------|
| 第 1 行 | 证照状态（正常 / 异常） | 同左（但判定依据见下表特例） |
| 第 2 行 | `行驶证` + 检验有效期 + **剩余/过期天数** | `行驶证` + 检验有效期（**不**挂剩余天数） |
| 第 3 行 | — | `等级评定` + 评定到期日 + **剩余/过期天数** |

---

## 沪牌特例（与通用规则不同 · 必读）

> **仅车牌以「沪」开头的车辆生效。** 非沪牌仍按通用规则（行驶证检验有效期）。

| 能力 | 通用规则（非沪牌） | **沪牌特例** |
|------|-------------------|--------------|
| **证照状态（正常 / 异常）** | 优先台账证照状态；缺省时按**行驶证检验有效期**是否过期 | **只按等级评定时间**是否过期（或未评定）判定；**不**看行驶证检验有效期，也**不**直接采用台账 `licenseStatus` |
| **剩余 / 过期天数** | 按行驶证检验有效期 | **按等级评定时间**；不以行驶证检验有效期计算 |

### 沪牌状态判定细则

| 等级评定时间 | 证照状态 |
|--------------|----------|
| 未录入 / 未评定 | **异常** |
| 已过期（早于今天） | **异常** |
| 未过期（含当日） | **正常** |

因此：沪牌可能出现「行驶证检验日仍很远，但状态已是异常」（等级评定已过期），或「检验日将到但状态仍正常」（等级评定未过期）——这是预期行为，不是数据错误。

---

## 临期色

剩余 ≤ 30 天：预警色；已过期：危险色。  
（沪牌该色挂在等级评定行的剩余天数上。）

## 空态

| 情况 | 表现 |
|------|------|
| 无检验有效期 | 行驶证行日期「未录入」 |
| 沪牌无等级评定 | 等级评定行「未评定」；状态为异常；无剩余天数 |
| 更多筛选「证照状态」 | 按**展示用判定结果**过滤（沪牌已按等级评定推导） |
