# 运营状态标签

列表「运营状态 / 客户」列主行、详情基本信息标题旁展示运营状态胶囊。

## 五档展示

| 展示文案 | 含义 | 悬停提示 |
|----------|------|----------|
| 租赁 | 已交付租赁业务项目 | 同左 |
| 物流 | 已交付物流业务项目 | 同左 |
| **在库-可交付** | 在库且可交付（证照 / 保险等允许交车） | 同左 |
| **在库-不可交付** | 在库但暂不可交付 | 同左；非运营台账另提示「固定为在库-不可交付」 |
| 退出运营 | 已退出运营 | 已退出运营，不再参与租赁及物流交付 |

悬浮运营状态胶囊时，展示上表对应定义（与车辆状态 Tag 同为 `title` 提示）。

## 旧值兼容

| 历史 / 过渡值 | 界面展示 |
|---------------|----------|
| 可运营 | 在库-可交付 |
| 待运营 / 代运营 | 在库-不可交付 |
| 库存可交付 | 在库-可交付 |
| 库存不可交付 | 在库-不可交付 |

筛选、库存 KPI、编辑选项均按「在库-可交付 / 在库-不可交付」展示；命中时兼容上述旧值。

## 非运营车辆

台账类型为「非运营车辆」时，运营状态强制「在库-不可交付」，不计入库存 KPI；悬停提示说明非运营固定态。
