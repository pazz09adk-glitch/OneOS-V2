# 列表 · 分类与筛选

## 分类 Pill（6 项）

全部车辆 / 租赁 / 物流 / 库存 / 非运营 / 退出运营。  
证照异常、保险异常**不在**顶部 Pill，统一在更多筛选中选择状态。

## 车牌主筛选

- 多选与 Excel 同列粘贴（换行 / 制表符）
- 主入口视觉强化（描边、浅底、外晕）
- 粘贴 / 多选后立即查询

## 更多筛选（17 项）

四大分组：地理与场地、车辆与资产、业务与项目、状态与合规。  
含运营城市、中国大区、品牌、型号、客户、部门、项目、业务类型、合同、所有权、运营公司、运营状态、证照状态、保险状态、车辆来源、租赁公司、停车场。

**正向**：展开 → 多选 → 看「匹配 N 辆」→ 查询  
**逆向**：重置 / 清空草稿后收起面板并刷新；未点查询时列表保持上次已应用条件（车牌即时查询除外）
