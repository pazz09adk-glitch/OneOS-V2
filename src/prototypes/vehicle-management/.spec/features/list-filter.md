# 列表 · 分类与筛选

## 分类 Pill（6 项）

全部车辆 / 租赁 / 物流 / 库存 / 非运营 / 退出运营。  
证照异常、保险异常**不在**顶部 Pill，统一在更多筛选中选择状态。  
租赁 / 物流 / 退出等主档**只通过 Pill**切换；更多筛选不再提供同名「运营状态」多选，避免与 Pill 语义打架。

## 车牌主筛选

- 多选与 Excel 同列粘贴（换行 / 制表符）
- 主入口视觉强化（描边、浅底、外晕）
- 粘贴 / 多选后立即查询

## 首行工具链

主搜索（车牌）→ 更多筛选 → **查询** → **重置** → 导出 / 导入 / 列设置。  
查询 / 重置后自动收起「更多筛选」面板（DESIGN §2.4.3）。收起态也可直接点首行查询 / 重置，无需先展开面板。

## 更多筛选（17 项）

四大分组：地理与场地、车辆与资产、业务与项目、状态与合规。  
含运营城市、中国大区、品牌、型号、客户、部门、项目、业务类型、合同、所有权、运营公司、**在库细档**（可交付 / 不可交付）、证照状态、保险状态、车辆来源、租赁公司、停车场。

**正向**：展开 → 多选 → 看「匹配 N 辆」→ 查询（或首行查询）  
**逆向**：重置 / 清空草稿后收起面板并刷新；未点查询时列表保持上次已应用条件（车牌即时查询除外）

## 与分类叠加

先按 Pill 分类，再套已应用筛选条件。在库细档可与「全部车辆 / 库存」叠加，精筛可交付或不可交付。
