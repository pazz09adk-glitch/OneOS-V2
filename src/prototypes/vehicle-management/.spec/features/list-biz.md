# 列表 · 业务部门 / 经理

## 起点 → 运作 → 闭环

- **起点**：台账「业务部门 / 经理」列
- **怎么运作**：展示该车当前履约的**租赁合同**或**物流合同**上挂载的业务归属
  1. **第 1 行**：业务经理（合同业务负责人）
  2. **第 2 行**：业务部门（合同归属部门）
- **闭环**：确认跟单人与归属部门后，可继续按更多筛选中的「归属业务部门」缩小范围

## 数据来源

| 字段 | 来源 |
|------|------|
| 业务经理 | 租赁 / 物流合同的业务经理（`manager`） |
| 业务部门 | 租赁 / 物流合同的归属业务部门（`department`） |

与「当前运维负责人」列无关：运维按停放区域匹配；本列只反映合同侧业务条线。

## 空态

未关联租赁 / 物流合同与项目时：展示「未关联业务经理 / 无业务部门」空卡（库存等非履约车辆常见）。

## 展示规则

| 情况 | 表现 |
|------|------|
| 有合同且有经理 / 部门 | 双行展示经理 + 部门 |
| 有合同但缺经理 | 「未指定经理」 |
| 有合同但缺部门 | 「未分配部门」 |
| 无合同无项目 | 空卡，不展示车辆自有组织字段冒充合同归属 |
