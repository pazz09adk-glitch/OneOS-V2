## 批量导入

三步：**下载模板 → 上传并选择重复策略 → 预检与确认**。

| 重复策略 | 含义 |
|----------|------|
| 跳过重复 | 已存在车辆识别代码则不导入 |
| 覆盖重复 | 用本次内容覆盖已有 |
| 报错 | 重复行进失败集，其余继续 |

主键：车辆识别代码。  

### 导入模板（`.xlsx`）

- 文件名：`车辆资产批量导入模板_OneOS.xlsx`
- 含车辆类型、公告型号、车牌、识别代码、来源等列
- **「车辆来源」列**：Excel **数据有效性 → 序列**下拉（自有 / 外租 / 挂靠），禁止自由输入，避免与系统枚举不符导致导入失败
- 仍可上传 `.csv` / `.xlsx`；推荐使用官方模板
