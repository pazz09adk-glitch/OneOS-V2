# 详情 · 侧栏（定位 / 证照情况 / 运维）

## 定位信息

优先级：**车机 → GPS 平台 → 人工**。

| 形态 | 展示 |
|------|------|
| 车机 / GPS | 在线或离线 + 省-市来源标签 + 详细地址 + 相对更新时间（悬停绝对时间） |
| 人工 | 省-市「人工」+ 未接入车机 / GPS 说明；可维护运营城市；保存后展示「最近修改时间」 |

左侧基本信息展开全部参数时，本卡片同步拉高。

## 证照情况

位置：运维负责人指派**上方**。  
图例：正常 / 临期 / 已到期 / 缺日期。  
点击条目预览：相关字段 + 图片（可翻页 / 下载）；无图「未上传」；字段空值统一「未上传」，不展示横杠。  
沪牌预览行驶证时额外展示年审有效期。  
详情不再提供独立「证照信息」Tab。

## 运维负责人指派

展示当前负责人，可调整；内附操作记录（时间、操作人、指派对象）。  
切换生命周期事件时不隐藏。  
字段定义与查/写权限见「运维负责人」专题：查询不设门槛；待办与业务操作仅该车负责人。
