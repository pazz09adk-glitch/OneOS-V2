# 详情 · 停放区域（停车场 / 维修站）

## 起点 → 运作 → 闭环

- **起点**：进入页内详情，基本信息第三列「停放」位
- **怎么运作**：
  1. 在库且已录入场站：字段名按场站类型显示为「停车场」或「维修站」，取值场站名称
  2. 非在库（租赁 / 物流履约、调拨中、异动中）：字段名保持「停放区域」，只读「车辆未在库」
  3. 在库但未录入：字段名「停放区域」，警示「未录入停放区域」
- **闭环**：确认车辆当前场站类型与名称，或理解未在库原因

## 场站类型判定

按场站名称识别（与列表辅行口径一致）：

| 命中关键词 | 类型 | 字段名 |
|------------|------|--------|
| 维修站 / 服务站 / 修理厂 / 检测站 | 维修站 | 维修站 |
| 其余有效名称 | 停车场 | 停车场 |

含「维修站停车场」「服务站停车场」等复合名时，**优先按维修站**认定。

## 未在库规则

| 情况 | 展示 |
|------|------|
| 运营状态为租赁 / 物流（履约中） | 车辆未在库（履约中不展示场站） |
| 车辆状态为调拨中 | 车辆未在库（调拨执行中不展示） |
| 车辆状态为异动中 | 车辆未在库（异动执行中不展示） |

详情**不再**单独展示「停车场」字段；类型信息并入本字段名。

## 与列表 / 运维的关系

- 列表「停放区域」列：主文为场站名称，辅行为停车场 / 维修站
- 运维自动匹配依据**最后停放区域**持久字段，与本处展示解耦（交车后列表停放可清空）
