# 详情 · 车辆全生命周期记录

## 起点 → 运作 → 闭环

- **起点**：进入详情，主区默认展示本卡片
- **怎么运作**：
  1. 事件名称 = 全部 → 倒序时间轴（搜索 / 展开明细）
  2. 右上角「事件名称」主筛选（视觉同列表主筛选入口）切换事件
  3. 已上线事件进业务列表；未上线显示「暂未上线，敬请期待」
  4. **关键事件总数**只展示**高频操作**次数卡，点击跳转对应阶段；入库 / 过户 / 销售 / 报废 / 出库等低频互斥终态不进指标条，改由时间轴查看
- **闭环**：定位到目标事件，或确认该事件尚未上线

## 概览区

| 区块 | 说明 |
|------|------|
| 事件数 / 时间跨度 | 两卡概览；**不**展示「当前视图」（由事件名称筛选自行表达） |
| 关键事件总数 | **仅高频**：验车、交车、还车、替换、异动、年审、交强险、商业险、调拨、故障、违章、事故、维修、保养 |

### 指标条不含（低频 / 互斥）

入库、过户、销售、报废、出库：生命周期终态或低频且彼此互斥（如销售后不可报废），指标条不展示；仍出现在「全部」时间轴与事件名称筛选中。

## 事件名称对照

| 事件名称 | 展示 |
|----------|------|
| 全部 | 倒序时间轴 |
| 交车 / 还车 / 替换 / 异动 / 年审 / 调拨 / 故障 / 违章 / 事故 | 业务列表（筛选与分页） |
| 交强险 / 商业险 | 保险采购记录（锁定对应险种） |
| 入库 / 出库 | 事件清单 |
| 验车 / 维修 / 保养 / 过户 / 销售 / 报废 | 敬请期待 |

## 约束

- 内容直接铺在外层卡片内，不套内层「轨迹」卡片
- 不含「运维负责人指派」事件（运维在右侧侧栏）
- 跨模块动作 Toast 演示
