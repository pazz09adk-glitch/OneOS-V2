# 列表 · 车辆里程考核任务预判

政策补贴里程考核（≠ 合同优惠里程考核）。

## 展示

- 完成进度 %（封顶 100%）
- 预判标签：预计可完成 / 有完成风险 / 预计无法完成 / 已完成
- 辅行：剩 xx km · 约 N 天 / 暂无法预计
- 无任务：空态文案

## 剩余里程与预计天数

1. **工单初始里程**：创建任务时填写；默认**车机** → **GPS** → **人工**
2. **已跑** = 当前实际里程 − 工单初始里程
3. **剩余** = 任务目标里程 − 已跑
4. **预计完成天数** = 剩余 ÷ 近 7 个活跃日日均（活跃日：日行驶＞20 km）

悬停辅行可看初始来源、已跑与剩余拆解。

## 预判口径

1. **预计可跑** = 近 7 活跃日日均 × 工单截止剩余天数
2. 对比任务剩余：
   - 预计可跑 **少于** 剩余 → **预计无法完成**
   - 预计可跑 − 剩余 **≤ 200 km** → **有完成风险**
   - 预计可跑 − 剩余 **> 200 km** → **预计可完成**
3. 活跃日不足 → 辅行「暂无法预计」，不打预判色标
