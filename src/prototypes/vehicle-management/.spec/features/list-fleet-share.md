# 列表 · 在租车型占比

## 起点 → 运作 → 闭环

- **起点**：进入列表，需要看清在租车型结构
- **怎么运作**：
  1. 主区固定 **TOP3 热门车型 + 第 4 卡「其他」**（汇总 TOP4 及以后全部品牌型号的在租辆数与占在租 %）
  2. 超过 3 种车型时，仍可用「查看全部车型」打开**排行表**后再点选具体型号
  3. 点击 TOP3 卡片 / 排行行：**立即**按该卡**品牌 + 型号**过滤台账（可在更多筛选中看到）；切到「全部车辆」、不展开更多筛选
  4. 点击「其他」卡：列表直接显示 **TOP4 及以后**全部品牌型号车辆（含库存等全状态），**不**往更多筛选写入品牌 / 型号多选
  5. 再点同一卡片 / 行：清除筛选，恢复全量
- **闭环**：台账已按车型过滤；可再次点击同一卡或「重置」恢复

## 关键规则

- 点击**不**弹明细框、**不**滚动锚点到列表、**不**展开「更多筛选」面板
- **不提供**业务线 Tab；统计口径始终为全部在租（租赁 + 物流）
- 主区 **4 卡位**：TOP3 +「其他」；车型总数 ≤3 时不出现「其他」
- 「其他」标题形如 `其他（N 种品牌型号）`，在租数 = TOP4 及以后在租合计，占在租 % 相对全部在租
- **卡内构成可读**：进度条下方必须同时展示 **色点 + 文案（租赁 / 物流 / 库存）+ 数字**，不得只留裸数字
- 区块头仍保留构成图例（与卡内文案一致，便于扫读）
- 「查看全部」用排行表（排名 / 型号 / 在租 / 占在租 / 构成条 / 租·物·库）
- 卡片信息分区：
  - **前方**：在租辆数 +「占在租 %」
  - **后方**：构成条 + 租赁 / 物流 / 库存（文案 + 数字）
- 进度条三色区分租赁 / 物流 / 库存（库存口径与分类 Pill 一致）
