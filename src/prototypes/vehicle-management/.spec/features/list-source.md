# 列表 · 车辆来源

## 起点 → 运作 → 闭环

- **起点**：台账「车辆来源」列
- **怎么运作**：双行展示资产获取方式；辅行按类型给出说明或来源公司
- **闭环**：确认来源类型后，可在更多筛选中按「车辆来源」「租赁公司」继续过滤

> **易混**：本列是资产来源（自有 / 外租 / 挂靠），**不是**运营城市的「来源·车机 / GPS / 人工」。

## 枚举（主行）

| 取值 | 含义 |
|------|------|
| 自有 | 自行采购持有 |
| 外租 | 向第三方租赁公司租用 |
| 挂靠 | 挂靠在其他主体名下运营 |

无值时主文「未录入」。

## 辅行逻辑

| 主行 | 辅行文案 |
|------|----------|
| 自有 | 固定：「该车辆为自行采购」 |
| 外租 | 租赁来源公司名称（`leaseCompany`）；缺漏时「未录入租赁来源公司」 |
| 挂靠 | 挂靠来源公司名称（同用 `leaseCompany` 字段承载）；缺漏时「未录入挂靠来源公司」 |

## 筛选联动

- 更多筛选「车辆来源」：按自有 / 外租 / 挂靠多选
- 更多筛选「租赁公司」：主要服务外租场景的来源公司过滤（与辅行公司名同源）

## 与相邻列区分

| 列 | 含义 |
|----|------|
| 车辆来源 | 资产获取方式 + 辅行说明 / 来源公司（本列） |
| 登记所有权 | 权属登记公司名称 |
| 运营公司 | 实际运营主体 |
