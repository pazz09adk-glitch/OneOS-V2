# 列表 · 登记所有权

## 起点 → 运作 → 闭环

- **起点**：台账「登记所有权」列
- **怎么运作**：展示车辆**登记所有权对应的公司名称**（行驶证 / 资产权属主体）
- **闭环**：确认权属公司后，可继续在更多筛选中按「登记所有权」缩小范围

## 展示规则

| 行 | 内容 |
|----|------|
| 第 1 行 | 公司名称（如「羚牛氢能科技(广东)有限公司」） |
| 第 2 行 | 固定辅文「登记所有权」 |

无值时主文展示「未录入」（辅文仍为「登记所有权」）。

## 数据来源（本期）

**目前通过批量导入写入**，不在台账行内直接编辑本列。

| 路径 | 说明 |
|------|------|
| 批量导入 | 导入模板含登记所有权（公司名称）；按车辆识别代码落档 |
| 更多筛选 | 可按已有公司名称多选过滤 |
| Admin「编辑档案」 | 正式环境仅 Admin 可兜底改档案字段（含本项）；非主录入路径 |

## 与相邻列区分

| 列 | 含义 |
|----|------|
| 登记所有权 | 权属公司名称（本列） |
| 车辆来源 | 自有 / 外租 / 挂靠等来源类型（及辅行说明） |
| 运营公司 | 实际运营主体，不等于登记所有权 |
