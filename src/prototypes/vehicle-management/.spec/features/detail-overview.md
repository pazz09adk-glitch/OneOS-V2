# 详情工作台 · 总览

## 目标

在同一原型内打开一车一档：基本信息、全生命周期、右侧定位 / 证照 / 运维，返回不离开模块。

## 起点 → 运作 → 闭环

- **起点**：列表点车牌或「查看详情」
- **怎么运作**：
  1. 顶栏：返回列表 +「车辆档案工作台」
  2. 主区：车辆基本信息 → 车辆全生命周期记录
  3. 侧栏：定位信息 → 证照情况 → 运维负责人指派
- **闭环**：办结查阅 / 维护后点返回，回到原列表上下文

## 布局原则

- 无顶部业务 Tab（不再用 Tab 切换基本信息 / 证照 / 型号等）
- 切换生命周期事件时，右侧侧栏始终保留
- 不做侧栏「详情页」独立下级入口
