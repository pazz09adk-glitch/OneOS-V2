# 列表 · 运营状态 / 客户

## 起点 → 运作 → 闭环

- **起点**：台账「运营状态 / 客户」列
- **怎么运作**：双行扫读运营状态与履约客户
- **闭环**：确认车辆运营态与当前合同客户后，可继续点合同编号或进详情

## 展示结构

| 行 | 内容 | 说明 |
|----|------|------|
| **上方** | 运营状态标签 | 五档胶囊：租赁 / 物流 / 在库-可交付 / 在库-不可交付 / 退出运营；**悬停**展示该档定义（细则见「运营状态标签」专题） |
| **下方** | 当前租赁 / 物流合同客户名称 | 取自已交付租赁或物流合同的客户；有客户时左侧带公司图标 |

## 空态

未关联租赁 / 物流合同客户时，下方展示「在库未出租」（辅文色）。

## 数据来源

| 行 | 字段口径 |
|----|----------|
| 运营状态 | `operateStatus`（经展示映射；非运营台账强制在库-不可交付） |
| 客户名称 | 履约中取合同客户（`customer` / 项目交付客户）；非租赁 / 物流履约则无客户名 |

运营状态标签色与五档含义见专题 `operate-status.md`（标注点可挂在首行状态胶囊上）。
