# 列表 · 人工运营城市可改

## 起点 → 运作 → 闭环

- **起点**：运营城市列辅行「来源·人工」或省市（人工来源时）
- **怎么运作**：
  1. 人工来源以主色下划线 +「修改 ›」引导
  2. 点击「来源·人工 / 修改」或省市 → 打开运营城市维护弹层（**不是**地图）
  3. 保存后城市更新，来源仍为人工，并**写入本次修改时间为更新时间**（列表辅行由「暂无时间」变为「更新 YYYY-MM-DD HH:mm」）
- **闭环**：完成人工运营城市修正，或取消关闭弹层

## 为何不能点地图

人工来源车辆**未接入车机和 GPS**，没有可用定位信息：

| 操作 | 结果 |
|------|------|
| 点省市 | 修改运营城市（维护） |
| 点「来源·人工 / 修改」 | 同上 |
| 期望打开定位地图 | **不允许** |

## 更新时间规则

| 时机 | 列表辅行时间 |
|------|----------------|
| 从未人工修改（无时间） | 「暂无时间」 |
| 保存运营城市后 | 「更新」+ 本次人工修改时分；悬停提示「人工修改时间 …」 |

## 三类来源速查

| 来源 | 可改城市 | 可看地图 |
|------|----------|----------|
| 车机 | 否 | 是 |
| GPS | 否 | 是 |
| **人工** | **是** | **否** |

完整对照见「运营城市列（定位 / 来源特殊规则）」。
