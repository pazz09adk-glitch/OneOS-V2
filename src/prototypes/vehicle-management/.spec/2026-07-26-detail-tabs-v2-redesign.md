# 车辆资产详情 Tab · OneOS V2 重布局规格

## 决策摘要

- 进入车辆详情后默认打开“生命周期”。
- 采用方案 A：V2 分区工作台。
- 生命周期、基本信息保留右侧运维负责人侧栏。
- 型号参数及后续 Tab 自动切换为全宽内容区。
- OneOS 1.2 车辆详情作为字段、功能和信息架构参考；视觉与组件必须使用 OneOS V2。
- 若参考页与当前 V2 字段或功能存在差异，以参考页为准；数据值继续使用当前 V2 数据源。

## 产品需求

### 目标用户

车辆运营人员、业务经办人、运维负责人和管理员。

### 核心任务

- 进入车辆详情后首先了解车辆生命周期状态与事件。
- 快速查阅车型技术参数和保养规则。
- 查阅车辆证照、证件状态、有效期和证件图片。
- 查询车辆的保险、租赁、事故、故障、违章、异动、调拨和年审记录。

### 本次范围

1. 修改车辆详情默认 Tab。
2. 重做型号参数的只读展示。
3. 按参考页信息架构重做证照信息。
4. 按参考页字段和功能重做保险记录至年审记录的布局。
5. 统一上述 Tab 的 OneOS V2 视觉、筛选、表格、分页和状态表达。

### 不在范围内

- 不重做生命周期内容。
- 不重做基本信息内容。
- 不修改车辆顶部摘要和定位信息的字段。
- 不新增后端接口、真实跨模块跳转或持久化能力。
- 不更换当前 V2 JSON 数据源。

### 内容与数据来源

- 字段、功能和信息架构参考：
  `http://localhost:53817/?projectId=oneos1.2&p=vehicle-management`
- 设计基底：
  `src/resources/design-system/DESIGN.md`
- 运行数据：`src/prototypes/vehicle-management/data/` 及现有车辆详情数据工具。
- 当前已有的查询、重置、分页、Toast 和图片预览行为继续复用。

## 整体信息架构

```text
┌ 返回列表  车辆档案工作台 ─────────────────────────────┐
│ 车辆基本信息 + 合规摘要          │ 定位信息            │
├──────────────────────────────────────────────────────┤
│ 生命周期｜基本信息｜型号参数｜证照信息｜保险记录｜…   │
├──────────────────────────────────────────────────────┤
│ 生命周期 / 基本信息：主内容区 + 右侧运维负责人侧栏     │
│                                                      │
│ 型号参数及后续 Tab：全宽内容区                        │
│ ┌ 分区标题 / 状态摘要 / 筛选区 ────────────────────┐ │
│ │ 描述网格、证照卡片或数据表格                     │ │
│ └──────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────┘
```

### Tab 与布局规则

- Tab 顺序保持：
  生命周期、基本信息、型号参数、证照信息、保险记录、租赁记录、事故记录、
  故障记录、违章记录、异动记录、调拨记录、年审记录。
- 默认 Tab 为 `lifecycle`。
- `lifecycle`、`basic` 使用主内容区加右侧栏。
- `model`、`license`、`insurance`、`lease`、`accident`、`fault`、
  `violation`、`movement`、`transfer`、`annual` 使用全宽内容区。
- 切换 Tab 不改变当前车辆上下文。
- 记录 Tab 保留自己的筛选、查询、重置和分页状态逻辑。
- 桌面宽表可横向滚动；窄屏不强行压缩所有字段。

## 型号参数

### 展示原则

- 移除类似禁用输入框的灰底字段容器。
- 使用 OneOS V2 只读描述网格：
  - 字段名为弱化辅助文字；
  - 字段值为主要信息；
  - 桌面端三列；
  - 长文本可跨列；
  - 窄屏降为单列。
- 缺失值显示“—”。
- 数字和金额使用等宽数字。

### 分区与字段

1. 基本情况：
   品牌、型号、车型、公告型号、燃料种类、车辆类型、车牌颜色、
   车辆长度、车辆宽度、车辆高度。
2. 轮胎情况：
   轮胎数量、轮胎磨损费用。
3. 电气情况：
   电池类型、电池厂家、储电量、电续航里程。
4. 供氢系统：
   氢瓶容量、仪表盘显示模式、氢续航里程。
5. 其他系统：
   冷机厂家。
6. 保养规则：
   养护项目、保养公里周期、保养时间周期、工时费、材料费、合计。

当前 V2 的字段名称、单位和数值继续使用；保养规则继续使用 V2 表格。

## 证照信息

### 结构

```text
┌ 证照索引 ───────────────────────────────────────────┐
│ 状态图例：●正常 ●临期 ●已到期 ●未上传               │
│ [行驶证●] [道路运输证●] [登记证●] [特种设备…] […]   │
└─────────────────────────────────────────────────────┘

┌ 行驶证                                      已上传 ┐
│ [证件图 1] [证件图 2]                              │
│ 注册日期       发证日期       强制报废日期           │
│ 2025-06-03     未上传         2040-06-03             │
│ 检验有效期至：2027-06-30 · 剩余 339 天               │
└─────────────────────────────────────────────────────┘
```

### 证照分类

1. 行驶证
2. 道路运输证
3. 登记证
4. 特种设备使用登记证
5. 特种设备使用标识
6. 加氢卡
7. 安全阀
8. 压力表

### 交互与状态

- 顶部索引展示每类证照状态。
- 状态分为正常、临期、已到期、未上传。
- 点击索引平滑定位到对应证照分区。
- 图片点击后打开现有全屏预览。
- 字段、图片数量和空状态与参考页一致。
- 未上传证照使用 V2 空状态，不生成伪造图片。
- 证照卡片使用 V2 卡片、Tag、边框、圆角、间距和状态色。

### 字段口径

- 行驶证：
  注册日期、发证日期、强制报废日期、检验有效期至。
- 道路运输证：
  经营许可证号、核发时间、证件有效期、审验有效期。
- 特种设备使用标识：
  下次检验日期。
- 加氢卡：
  卡片信息；未绑定时显示规范空状态。
- 安全阀：
  本次检验日期、下次检测日期。
- 压力表：
  本次检验日期、下次检验日期。
- 登记证、特种设备使用登记证：
  以证件图片和现有可用字段为主。

## 保险记录至年审记录

### 统一页面骨架

```text
状态 / 概览（保险记录专用）
筛选区：字段控件 ─────────────── [重置] [查询]
数据表：参考页字段与操作
底栏：共 N 条 ──────────────── 分页与每页条数
```

- 筛选控件、日期范围、Select、查询、重置使用 V2 公共组件。
- 筛选展开状态下点击查询后应用条件并收起。
- 重置清空条件并收起。
- 表头、空值、日期、金额、状态、链接、操作列和分页遵循 V2。
- 表格横向溢出时在内容区内滚动。
- 无附件、无数据、无权限操作使用现有公共状态。

### 保险记录

- 险种概览：
  交强险、商业险、超赔险、驾意险、货物险。
- 展示保险状态、当前保单、到期日、剩余/过期天数。
- 采购历史字段：
  保险导入时间、操作人、类型、保单号、保险状态、保险公司、
  付款时间、到期日期、保单文件。
- 保单文件继续支持预览、下载。

### 租赁记录

- 筛选：
  合同编码、项目名称、客户名称、业务类型。
- 字段：
  合同编码、项目名称、客户名称、业务类型、交车日期、交车人、
  还车日期、还车人。
- 保留合同、项目、交车和还车入口。

### 事故记录

- 筛选：
  事故时间、客户名称、事故等级、事故状态。
- 字段：
  事故编码、事故时间、事故地点、事故类型、客户名称、
  我方定损金额、对方定损金额、责任划分、事故状态、结案时间。

### 故障记录

- 筛选：
  上报时间、故障编号、故障等级、故障类型、解决情况、AI 匹配状态。
- 字段：
  故障编号、解决情况、车牌号、车辆品牌、车辆型号、运营公司、
  故障等级、故障类型、故障描述、上报时间、解决时间、AI 匹配状态、
  最后操作人、操作。
- 操作列使用全局 `OperationActions` 规范。

### 违章记录

- 筛选：
  违法时间、客户名称、缴费状态、是否处理。
- 字段：
  违法时间、违法地点、违法行为、扣分、罚款金额、
  缴费状态、是否处理、采集单位。

### 异动记录

- 筛选：
  异动开始日期、异动目的地、异动类型。
- 字段：
  异动开始日期、异动预计结束日期、异动状态、异动目的地、
  目的地名称、异动类型、预计异动里程、异动开始里程、
  异动开始电量、异动开始氢量、异动结束里程、异动结束电量、
  异动结束氢量、创建人、创建时间。

### 调拨记录

- 筛选：
  调拨日期、调出人、接收人。
- 字段：
  调拨日期、调出人、接收人、出发区域、接收区域、调拨方式、
  出发停车场、接收停车场、接收日期。

### 年审记录

- 筛选：
  完成时间、检验有效期、办理人。
- 字段：
  检验有效期至、检测服务站名称、检测费用、二保服务站名称、
  二保费用、整备服务站名称、整备费用、办理人、完成时间。

## 组件边界

- `DetailView`：
  默认 Tab、Tab 切换、全宽/侧栏布局选择。
- `DetailModelParamsTab`：
  型号参数分组和保养规则。
- `DetailLicenseTab`：
  证照索引、状态、锚点定位、图片预览和证照分区。
- 各 `Detail*RecordsTab`：
  各自负责筛选、查询、重置、表格、操作和分页。
- 共享详情样式或轻量组件：
  分区标题、只读描述网格、记录筛选壳、表格底栏。

不把各业务 Tab 的状态和数据逻辑集中到 `DetailView`。

## 数据与错误处理

- 当前 V2 JSON 和数据工具是唯一运行数据源。
- 参考页只用于字段、功能和信息架构校准。
- 缺失字段统一显示“—”或规范空状态。
- 缺失证照图片不生成占位证件。
- 跨模块入口继续使用现有 Toast。
- 不新增网络请求、路由依赖或持久化逻辑。
