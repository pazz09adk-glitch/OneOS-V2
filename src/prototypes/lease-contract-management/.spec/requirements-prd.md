## 2. 列表模式（默认）

对齐 `.spec/requirements-prd-list.md`：

1. **4 张财务向 KPI**：在计合同金额、履约车辆、待我审批、草稿待提交  
2. **状态 Pill**：全部 / 待我审批 / 履约执行中 / 草稿箱  
3. **搜索 + 更多筛选 + 导出**；展开「更多筛选」为 **13 项**（含模板联动标准合同名、结束日期「至」）；点击 **查询 / 重置** 后**自动收起**筛选栏并展示结果（OneOS V2 §2.4.3）  

4. **主表列**：项目名称/编号、客户与签约公司、履约与审批状态、签署与车辆交付、合同金额、查看详情/更多操作  
5. **车辆子表**：展开后展示交车/还车/账单/里程与「还车办理」（Markdown §7.2.1）  
6. **操作弹窗**：编辑/删除/撤回/授权人/附加费/转三方/试用转正式/终止/上传盖章件（§8）

---

## 3. 看板模式

四列：草稿阶段 · 待我审批/盖章中 · 履约执行中 · 已终止/归档。卡片可进主从详情；草稿列可新建。

---

## 4. 主从/表单模式

左：可搜索合同任务列表。右：选中合同工作台（车辆履约子表 / 资质与授权人 / 审批节点 / 附加费用），与列表共用同一套弹窗与数据。
