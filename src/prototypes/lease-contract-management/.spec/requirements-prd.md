## 2. 双轨状态词典（强制）

合同有两套正交语义，**禁止揉成一个标签前半/后半**：

### 轨 A · 合同阶段（分流）

用于：列表 Pill、看板列、Bento KPI 点击分桶、行内 Tag **次行**。

| 阶段 | 判定（原型） | 文案 |
|---|---|---|
| 草稿 | `contractStatus = draft` | 草稿 |
| 审批中 | `contractStatus = submitted` | 审批中 |
| 进行中 | `contractStatus = active` | 进行中 |
| 已终止 | `contractStatus = terminated` | 已终止 |

Pill 另加 **全部合同**（不分桶）。

**不做**：阶段文案写成「待我审批 / 履约执行中 / 草稿箱 / 盖章中」；盖章属签署闭环，不进阶段桶。

### 轨 B · 审批进度 · 合同类型（单条）

用于：列表「履约与审批状态」列 **主 Tag**。

```text
{审批状态文案} · {标准合同 | 非标准合同}
```

审批文案：未提交 / 待审批 / 审批中 / 审批通过 / 审批驳回 / 审批终止 / 撤回。  
类型来自 `approvalType`（`standard` / `non_standard`）。

Tag **次行**：

- 固定展示轨 A 阶段文案  
- **仅当**审批态为待审批/审批中时，追加 ` · {当前节点人}`  
- 禁止把「归档完成 / 未提交」等结果文案塞进「节点人」槽位冒充次行

签署方式（线上电子签 / 线下人工）独立列展示，**不拼进主 Tag**。

### 允许组合（摘要）

| 阶段 | 常见审批态 |
|---|---|
| 草稿 | 未提交、撤回、驳回后回草稿 |
| 审批中 | 待审批、审批中 |
| 进行中 | 审批通过（履约中） |
| 已终止 | 审批终止或合同终止归档 |

## 3. 列表模式

1. **Bento KPI（4 张 · 阶段）**：草稿 / 进行中 / 审批中 / 已终止；点击 = 切换阶段 Pill（与 Pill 同桶）；选中态描边  
2. **状态 Pill**：全部合同 / 草稿 / 进行中 / 审批中 / 已终止  
3. **搜索 + 更多筛选 + 导出**；13 项更多筛选；查询/重置后自动收起（§2.4.3）  
4. **主表列**：项目信息（名只读 + **编号进详情**）/ 租赁订单 / 客户与签约公司 / 审批 Tag（双轨）/ 签署方式 / 合同金额 / 操作  
5. **车辆子表** + **操作弹窗**（编辑进全页表单；其余弹窗不变）

---

## 4. 看板模式

四列与阶段桶一致（流程序）：

**草稿 → 审批中 → 进行中 → 已终止**

卡片可进主从；草稿列可新建。卡片上可带轨 B 短标（审批 · 标准/非标），**列名不得再写盖章/待我审批**。

---

## 5. 主从工作台

左：合同列表。右：履约/资质/审批节点/附加费。  
**编辑草稿/驳回** → 同页全页表单；主从以只读与履约操作为主。
