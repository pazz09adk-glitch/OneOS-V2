## 1. 一句话与目标

**一句话**  
运维承接 AI 故障机器人入库的原始记录，完成处置、挂起与归档，并满足 30 天闭环与临期/逾期催办演示；证据链支撑日后向整车厂索赔。

**要解决的问题**  
- AI 上报后缺少统一处置台账与证据留存  
- 挂起与闭环时限不清，临期易漏催  
- 工作台运维看板「故障登记」需与真实处置口径一致  

**本期目标**  
1. 菜单：车辆运维 → 故障处置（**OneOS V2 三视图：列表 / 看板 / 主从表单**；对标租赁合同母版）  
2. 任务状态：待处理 / 处理中 / 挂起 / 已归档  
3. 证据链多附件 + 归档硬门槛  
4. 通知记录与短信/邮件模板演示  
5. 工作台预警 KPI + 运维看板同源统计  
6. 浅色 / 暗色双模式（`data-ds-mode` / `data-oneos-theme`）  

**非目标**  
- AI 对话界面、真实短信邮件通道  
- 品牌车型部位等级完整统计看板、一键故障证明（本期界面不展示入口）

## 2. 用户与故事

| 角色 | 故事 |
|------|------|
| 运维 | 从列表或看板接手待处理，主从视图分次保存处置与证据，挂起须填原因，达标后归档 |
| 运维主管 | 查看逾期升级通知记录，督办闭环；看板看阶段积压 |
| 多角色（如王冕兼运维） | 工作台预警见故障临期/逾期/待处理积压 |

**用户故事（起点 → 运作 → 闭环）**  
1. As a 运维, I want AI 上报后自动出现待处理记录（含聊天摘要与图视频）, so that 我能开始处置。  
2. As a 运维, I want 分次保存处理中并上传证据, so that 索赔材料可追溯。  
3. As a 运维, I want 挂起时必填原因且不停表, so that 时限仍受控。  
4. As a 运维, I want 归档时系统硬校验关键字段与附件, so that 未齐套不能闭环。  
5. As a 运维/主管, I want 临 7 天与超 30 天催办留痕（演示）, so that 知道谁被通知。  
6. As a 运维角色用户, I want 工作台预警与看板故障登记同步本模块, so that 一眼看到积压与闭环率。  
7. As a 运维, I want 在列表 / 看板 / 主从三视图间切换且「处置 / 快速操作」进入主从填报, so that 与 OneOS V2 台账壳一致。  
8. As a 运维, I want 打开故障详情全页时左侧看车辆上下文、描述与 AI 摘要、处置证据，右侧固定催办/督办留痕（有则含挂起历史）且画布铺满无居中限宽, so that 督办痕迹一眼可见、宽屏不留大片空白。

## 3. 验收重点

1. 种子含待处理/处理中/挂起/已归档/临期/逾期；列表以**故障编号**为主列引导查看，车辆信息正文展示车牌与品牌型号；**故障部位**、**故障等级**分列。列表「故障等级 / 解决情况 / 任务状态」为只读正文：默认正文色，仅 L1·未解决用警告红、L2·临时排故·已挂起用预警橙；不用绿/蓝/紫状态胶囊。  
2. 顶栏可切换 **列表 / 看板 / 主从**；看板列 = 四状态；列表操作列：**处置**外侧、**查看记录**进更多（打开挂起与通知 Tab）；看板「快速操作」仍切入主从并选中单据。  
3. Bento KPI：待处理 / 处理中 / 临期 / 逾期；点击与 Pill Tabs 联动筛选。工作台 KPI 深链（`#filter=due-soon|overdue|pending`）仍可叠加生效。  
4. 「更多筛选」：车牌号选择器、最后完成时限区间、任务状态、等级、品牌车型、故障号。  
5. 列表「最后完成时限」：截止日 +「剩 N 天」或「逾期 N 天」（已归档「已闭环」）。  
6. 导出 CSV：车牌号、品牌、型号、故障号分列；含部位、等级、状态、时限。  
7. 主从右侧：保存→处理中；挂起无原因不可提交；挂起不可直接归档；缺时间/地点/部位/等级/结果/证据任一不可归档。  
8. 主从 Sub-tabs：处置主档（含 AI 原始记录）/ 证据链 / 挂起与通知。  
9. **故障详情全页**：左主（上下文 / 描述·AI / 处置证据）+ 右约 340px 催办与督办留痕（挂起历史有则同侧第二卡）；宽屏铺满、无 960 居中限宽；窄屏（≤1023）右栏沉底单列。处置填报表单仍可独立限宽。  
10. 主色 Stripe Violet `#533AFD`；浅/深双色可用。  
11. 工作台 ops 三类故障预警；运维看板故障登记总数/已归档/闭环率同源。  

数据：本地种子 + localStorage；**未接真实 API**。
