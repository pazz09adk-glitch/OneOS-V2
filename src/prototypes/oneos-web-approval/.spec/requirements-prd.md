# 审批中心 (V2) · 产品需求说明（PRD）

> **页面类型**：OneOS V2 全局定版规范原型  
> **设计标准**：`src/resources/design-system/DESIGN.md`  
> **核心变更**：原 4 个离散子页面合并为单原型（1 页 4 Tab + 主从）；详情采用**全业务通用骨架**；业务字段只来自现成审批中心样例，标题与审批流编号套用新规范。

---

## 1. 目标与价值

提供统一的审批流作业平台。用户在一个页面内办理待办、追踪发起事项、检索已办与查阅抄送。详情不按业务类型做专属页，统一壳层承载不同业务单据，降低学习成本并避免演示造数。

---

## 2. 核心功能与架构

### 2.1 侧栏与页面收拢
- 侧栏仅保留单个「审批中心」入口（`oneos-web-approval`）。
- 已移除旧版发起/待办/已办/抄送四个下级菜单。

### 2.2 1 页 4 Tab
1. **我的待办**：待当前用户审批的单据，附未办数量徽标；
2. **我发起的**：本人提交的申请及流转状态，审批中可「撤销申请 / 评论」；
3. **我的已办**：本人已通过或终止的历史；
4. **我的抄送**：知会抄送单据。

### 2.3 主从 Split
- **左侧（400px）**：4 Tab 完整可见；搜索 + 全部审批类型筛选。
- **左卡（钉钉式）**：`{发起人}提交的{短类型}-{短摘要}` → ≤2 行「标签：值」→ 「等待××处理」+「YYYY.MM.DD 发起」。审批流编号、业务单号、风险长文案不进左卡（详情展示；搜索仍覆盖两类单号）。
- **右侧通用详情骨架**（全业务同一结构，不按 type 分支专属区块）：
  1. **页头**：标注「审批流编号」+ `AP-…` 紫胶囊 + 纯图标复制；新规范主/副标题；业务类型 Tag（样例确有加急时再加「加急」）；Meta：发起人 · 时间 · 「{角色}审批中」等；
  2. **风险提示**（仅样例有 risks 时）：标题固定为「风险提示」，文案来自样例；
  3. **申请信息**：关键摘要（短）+ 可折叠分组（费用/合同/客户等，对齐合同查看口径）；默认展开费用与合同，客户档案默认收起，避免字段墙；
  4. **明细**（样例有行项目时）：通用表格，标题固定为「明细」（如租赁订单车辆行）；
  5. **附件**（样例有则显示）；
  6. **审批流**：仅垂直贯穿；按现网 Warm-Flow **完整定义链**展示（含未到达的待审批节点），不只显示已执行+当前；步骤标题为角色名；节点人时意见来自样例链路；
  7. **底栏**：待办「通过 / 终止 / 评论」（对齐现网）；我发起的审批中「撤销申请 / 评论」。弹窗字段对齐现网，不新增未核对的转交/加签主按钮。

### 2.4 标题与编号新规范
| 字段 | 规则 | 列表 | 详情 |
|------|------|------|------|
| 审批流编号 | `AP-{业务码}-{YYYYMM}-{流水}` | 不展示（可搜） | 页头紫胶囊 + 复制 |
| 业务单据号 | 样例原业务号（如 `HT-CG-…`） | 不展示（可搜） | 仅申请信息 KV |
| 主标题 | `{主体对象}+{数量/标的}+{动作}`，只重组样例已有信息 | 不直接展示 | 20px 标题 |
| 副标题 | `{项目/主体} · {关键约束}` | — | 副文案 |
| typeLabel | 定版短名（如「车辆采购审批」） | 短类型入左卡合成标题 | Tag |
| 列表标题 | `{发起人}提交的{短类型}-{短摘要}` | 展示 | — |

**允许改写**：仅审批流编号、主/副标题、typeLabel、页头「审批流编号」展示名。  
**禁止改写**：金额、数量、风险、意见、附件、审批人、时间等业务事实；不为演示新增无样例来源的单据或字段。

### 2.5 样例与造数约束
- 列表与详情样例取自现网 `lnoneos.com` 当前登录账号（`yaoshoutao` / 姚守涛）四菜单真实单据；字段、金额、审批人、时间不扩写；禁止保留他账号或原型自造单。
- 本账号现网待办为 0 时，原型可保留 **1 条**现网真实字段待办，专供验收「通过 / 终止 / 评论」弹窗；抄送仍为空。
- **待办弹窗**（对齐现网 `flow-actions`）：
  - 通过 → 标题「审批通过」：通知方式（站内信默认勾选不可取消 / 邮件 / 短信）、附件上传、抄送人、下一步审批人、审批意见；
  - 终止 → 标题「审批终止」：文案「确定终止当前审批流程吗？」+「审批意见(可选)」；
  - 评论 → 标题「添加评论」：必填「评论内容」（≤500 字、字数计数）；支持上传附件（PDF / 图片 / Office 常用格式，最多 10 个）。
- **我发起的**：底栏「撤销申请 / 评论」；撤销为确认框「确定要撤销该申请吗？」；评论同待办。
- 不把保险/账单等业务专属详情页结构迁入通用壳；分组标题对齐现网合同/结款查看口径（费用汇总 / 合同信息 / 客户信息）。

### 2.6 壳层与业务类型
- 容器 `height:100%` + flex 链适配 Make iframe；顶栏仅「审批中心」+ 重置。
- 支持 19 类需审批业务；**不含**已下线停车场审批。

## 3. 用户故事

### US-01 办理待办审批
- **起点**：进入「审批中心」，默认「我的待办」；
- **运作**：点选左卡 → 右侧通用骨架 → 底栏「通过 / 终止 / 评论」并打开对应弹窗填写；
- **闭环**：通过或终止后进入「我的已办」，待办徽标递减；评论写入审批流。

### US-02 追溯已发起申请
- **起点**：切换「我发起的」；
- **运作**：查看样例发起单；审批中可「撤销申请」（确认框）或「评论」；
- **闭环**：确认进度、撤销成功或评论落在审批流。

### US-03 多业务同一壳层
- **起点**：在筛选或 Tab 中切换不同业务类型样例；
- **运作**：详情始终为「页头 → 风险（可选）→ 申请信息 → 附件（可选）→ 审批流 → 底栏」；
- **闭环**：壳层一致，仅 KV/节点内容随样例变化。

## 4. 视觉与响应式

1. 主色 `var(--oneos-primary, #533AFD)`，Light / Dark 双色；
2. 金额、车辆数、编号使用 `tabular-nums`；
3. ≤767px 自适应卡片化与 Bottom Sheet，触控高 ≥44px。
