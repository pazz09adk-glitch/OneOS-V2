# 租赁合同 H5 移动端 · AutoPRD

## 1. 模块定位

| 项 | 说明 |
|---|---|
| 模块名称 | 租赁合同 H5 移动端（微信小程序 / 小羚羚 App 嵌套） |
| 交互原型 | `/prototypes/oneos-v2-h5-lease-contract` |
| 设计规范 | OneOS Design System **v2** H5 Mobile Standard |
| 触控规范 | 点击热区 ≥ 44px · 吸底 Bottom Sheet · 100% 移动端自适应 |

## 2. 功能特征

- **3 视图支持**：列表卡片、看板 Pipeline、主从详情 Mode。
- **Bottom Sheet 交互**：高阶筛选、日期选择、状态过滤均使用固定吸底面板。
- **关联 PC 端**：PC 端 `/prototypes/lease-contract-management` 聚焦桌面大盘台账管理，H5 移动端独立作为 App/小程序嵌页面。
