# 王冕分身外网对话（wangmian-twin-chat）

| 项 | 内容 |
|----|------|
| 模块 | 外网可访问的分身对话页 |
| 形态 | 单页：文本 / 语音 / 截图 |
| 发布 | 对象存储静态托管（prototype.lnoneos.com） |

## 1. 总览

把「王冕数字分身」能力做成**可外发**的对话页：同事或业务方打开链接即可聊。对象存储托管前端；大模型通过用户本机配置的 OpenAI 兼容接口调用（密钥不进仓库）。

## 2. 目标 / 非目标

**目标**

- 文本对话，分身口吻（全宇宙无敌帅的王冕的分身 + 李云龙腔 + 调皮招呼）
- 语音输入（浏览器语音识别转文字）
- 截图/图片附件，有模型时走多模态
- 填写姓名用于招呼；王冕称「我的本尊」
- 未配 Key 时演示模式可点可看

**非目标（本期）**

- 不在静态页里硬编码平台 Key
- 不内嵌完整 OneOS 知识库检索（演示需说明）
- 不直连云效建单
- 不做账号体系 / 会话云端持久化

## 3. 角色

| 角色 | 做什么 |
|------|--------|
| 访客（开发/业务） | 打开公网页，配置可选 API，对话 |
| 本尊王冕 | 同页验收口吻与交互；决定是否提供团队网关 |

## 4. 用户故事

### US1 打开即聊（演示）

- **起点**：打开公网链接  
- **运作**：看到调皮招呼；可打字、语音、截图发送；演示模式回分身腔回复  
- **闭环**：无需登录即可体验交互  

### US2 接入真模型

- **起点**：点「接入模型」  
- **运作**：填姓名、Base URL、API Key、模型名，保存到本机；之后对话走兼容接口  
- **闭环**：真模型按系统提示以分身身份回复；失败有可读错误  

### US3 截图问诊

- **起点**：上传界面截图（可加文字）  
- **运作**：有模型则多模态理解；演示模式提示已收到图并给通用建议  
- **闭环**：得到可执行的产品/交互建议  

## 5. 正逆向

| 正向 | 逆向 |
|------|------|
| 未配 Key → 演示回复 | 浏览器无语音 API → 提示改 Chrome/打字 |
| 已配 Key → 调 chat/completions | CORS/鉴权失败 → 提示检查网关与 Key |
| 姓名=王冕 → 叫我的本尊 | 空发送且无图 → 不发 |

## 6. 风险

- 浏览器直连模型易遇 CORS，需团队网关或代理  
- Key 在访客本机，勿在公共电脑保存  
- 无 KB 时业务口径可能飘，页面需标明演示边界  

## 7. 验收

1. 公网打开页可见招呼与发送栏  
2. 未配 Key 发一条有演示回复  
3. 配兼容 API 后可真聊（环境允许时）  
4. 语音（Chrome）可写入输入框；截图可预览发送
