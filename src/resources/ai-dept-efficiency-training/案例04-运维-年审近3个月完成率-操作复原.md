# 案例 04 · 运维提效：年审管理近 3 个月完成率（操作复原 + AI 用法）

> 培训用途：运维同事关心「近 3 个月要审多少、已审多少、完成比例」  
> 演示时间：2026-07-24  
> 入口：运维管理 → 车辆业务 → 年审管理（`/operations/vehicle-biz/annual-review`）

---

## 1. 一句话结论

打开 **年审管理** 后，AI 自动汇总（与页面 KPI 对齐）：

| 指标 | 数量 |
|------|------|
| 近 3 个月需要年审（待办） | **149** |
| 其中已逾期 | **20** |
| 已年审（已完成） | **141** |
| **完成比例** | **48.62%** |

公式：`141 ÷ (141 + 149) = 48.62%`

---

## 2. 业务目标

| 问题 | 交付 |
|------|------|
| 近 3 个月需要年审多少辆？ | 待办任务数（含逾期） |
| 已年审多少辆？ | 已完成数 |
| 比例？ | 已年审 / (已年审 + 需年审待办) |

---

## 3. 口径说明（分享时必讲）

| 口径 | 定义 |
|------|------|
| 需要年审 | 年审管理 **待办任务**（`reviewStatus=0`）。当前 149 辆的检验到期分布在 **已逾期 ~ 2026-09**，即近窗内应办未办 |
| 已年审 | 年审管理 **已完成**（`reviewStatus=2`，共 141）。办结后系统会把检验到期日滚到次年，**不能**再用「当前到期日」反查已办车辆 |
| 完成比例 | 已年审 ÷ (已年审 + 需年审待办) |
| 对齐页面 | 待办 149 / 已逾期 20 / 已完成 141 与页顶 KPI 一致 |

---

## 4. 操作复原（人工路径）

1. 登录 OneOS  
2. 菜单：**运维管理 → 车辆业务 → 年审管理**  
   直达：https://lnoneos.com/operations/vehicle-biz/annual-review  
3. 看页顶：待办任务、已逾期、已完成  
4. 计算：完成比例 = 已完成 ÷ (已完成 + 待办)

> 人工痛点：要自己算比例；按月拆待办需导出后再透视。

## 6. AI 路径

### 6.1 提示词（可复制）

```text
打开运维管理 → 车辆业务 → 年审管理。
汇总近3个月：
1）需要年审的车辆总数（待办，含逾期）
2）已年审车辆总数（已完成）
3）完成比例 = 已年审 / (已年审 + 待办)
输出简表 + CSV，并与页面顶部 KPI 对齐说明。
```

### 6.2 步骤复原

| 步骤 | AI | 对应人工 |
|------|----|----------|
| 打开年审管理 | 进菜单/URL | 点菜单 |
| 拉待办 + 已完成列表 | reviewStatus=0 / 2 | 看 KPI / 导出 |
| 计数并算比例 | 汇总 | 计算器 |
| 按到期月 / 办理月拆解 | 分组 | 透视表 |
