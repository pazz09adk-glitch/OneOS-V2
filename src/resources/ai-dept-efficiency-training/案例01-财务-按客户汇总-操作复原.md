# 案例 01 · 财务提效：租赁业务按客户汇总（操作复原 + AI 用法）

> 培训用途：把一次真实操作拆成「人怎么做 → AI 怎么代做」  
> 演示时间：2026-07-24  
> 数据范围：OneOS 租赁业务明细 · **全部月份 / 全部部门 / 全部业务员**（未额外筛选）

---

## 1. 一句话结论

财务要看「每个客户的应收、实收、未收、总成本、盈亏」。  
系统页面只有行级明细 + 全量 KPI，**没有按客户汇总视图**。  
用 AI 打开页面、拉全量明细、按客户聚合后，约 **1 分钟**产出可分享的汇总表（本轮：2311 行明细 → **81 个客户**）。

---

## 2. 业务目标（交付物）

| 交付物 | 说明 |
|--------|------|
| 按客户汇总表 | 客户名称 + 应收 + 实收 + 未收 + 总成本 + 盈亏 |
| 校验 | 客户合计应与页面顶部 KPI 一致 |
| 可选解读 | 未收 Top、亏损 Top，供催收/经营会用 |

---

## 3. 操作复原（人工路径）

若不用 AI，同事可按同样路径自己做：

1. 登录 [OneOS](https://lnoneos.com)
2. 菜单：**业务管理 → 租赁业务统计 → 租赁业务明细**  
   或直达：https://lnoneos.com/business/lease-statistics/lease-business-detail
3. 筛选保持默认（或按需要选「统计月份 / 业务部门」）→ 点 **查询**
4. 看顶部 KPI（全量口径）：
   - 应收总计 **7,619,949.90**
   - 实收总计 **6,468,070.10**
   - 未收总计 **1,151,879.80**
   - （页面 KPI 另有押金/减免等；总成本、盈亏在表格列与 summary 中）
5. 点 **批量导出**，用 Excel 透视表：行 = 客户名称，值 = 求和（应收合计、实收金额、未收、总成本、盈亏）

> 人工痛点：导出 + 透视重复劳动；口径容易选错列；亏损/未收客户要再排一次序。

---

## 4. AI 路径（本轮实际做法）

### 4.1 对 AI 说的话（可直接复制给同事）

```text
打开 https://lnoneos.com/business/lease-statistics/lease-business-detail
（已登录或先让我登录）。
按「客户名称」汇总租赁业务明细的：应收、实收、未收、总成本、盈亏。
筛选用当前默认（全部月份/部门/业务员）。
输出：
1）按客户汇总表（CSV）
2）合计校验是否等于页面 KPI
3）未收 Top5、亏损 Top5
```

### 4.2 AI 实际执行步骤（复原）

| 步骤 | 做什么 | 对应人的动作 |
|------|--------|--------------|
| ① 登录进系统 | 复用已登录浏览器会话 | 打开 OneOS 并登录 |
| ② 进入明细页 | 打开租赁业务明细 URL | 点菜单到该页 |
| ③ 确认口径 | 分组键 = **客户名称**（不是「项目」） | 明确统计维度 |
| ④ 取数 | 调用列表接口分页拉取 2311 条 | 批量导出 Excel |
| ⑤ 汇总 | 按 `customerName` 对五项指标求和 | Excel 透视表 |
| ⑥ 校验 | 客户合计 vs 页面 summary KPI | 与顶部数字对一下 |
| ⑦ 产出 | CSV / JSON + 解读要点 | 发邮件/贴群 |

### 4.3 字段口径（已对齐线上）

| 汇总指标 | 明细字段 | Summary KPI 字段 |
|----------|----------|------------------|
| 应收 | `receivableTotal`（应收合计） | `receivableTotal` |
| 实收 | `receivedAmount`（实收金额） | `receivedAmount` |
| 未收 | `outstanding`（未收） | `outstanding` |
| 总成本 | `totalCost` | `totalCost` |
| 盈亏 | `profitLoss` | `profitLoss` |
| 分组 | `customerName` | — |

## 6. 从过程到「AI 怎么用」（培训要点）

| 人工能力 | 能否交给 AI | 说明 |
|----------|-------------|------|
| 找到菜单/页面 | ✅ 可 | 给 URL 或菜单路径即可 |
| 登录 | ⚠️ 半自动 | 首次需人登录；之后可复用会话 |
| 选筛选条件 | ✅ 可 | 要在提示词写清月份/部门 |
| 导出 + 透视 | ✅ 可 | AI 拉数汇总更快 |
| 口径确认 | ❌ 需人 | 「按客户还是按部门」必须人定 |
| 催收/经营决策 | ❌ 需人 | AI 只排 Top，拍板仍是业务 |

**可复用公式**：  
`业务目标` + `系统入口` + `筛选条件` + `分组维度` + `指标清单` + `输出格式` + `校验标准`

## 7. 给同事的最小提示词模板

```text
【部门】财务
【目标】按客户汇总租赁业务：应收、实收、未收、总成本、盈亏
【入口】https://lnoneos.com/business/lease-statistics/lease-business-detail
【筛选】全部月份 / 全部部门 / 全部业务员（或改成：统计月份=YYYY-MM）
【分组】客户名称
【输出】CSV 汇总表 + 与页面 KPI 校验 + 未收Top5 + 亏损Top5
```
