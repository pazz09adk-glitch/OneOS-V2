## 2. 业务目标

| 问题 | 交付 |
|------|------|
| 各站点加氢车次数？ | 按加氢站名称计数 |
| 加氢总量？ | sum(加氢量 kg) |
| 平均加氢单价？ | 加氢总价合计 ÷ 加氢总量 |
| 已核对 / 未核对？ | 按核对状态计数 |

---

## 3. 操作复原（人工路径）

1. 登录测试环境：https://dev-oneos.lnh2e.com  
2. 打开侧栏 **车辆氢费明细**  
3. 展开筛选：年=2026，月=1～6（或分月导出后合并）  
4. 导出 Excel → 透视：行=加氢站名称；值=计数、加氢量求和、加氢总价求和；再算均价；再按核对状态计数  

> 人工痛点：半年约 4 万行，分月导出再合并费时。

## 5. 口径说明

| 项 | 定义 |
|----|------|
| 环境 | **测试环境** `dev-oneos.lnh2e.com` |
| 期间 | `refuelYear=2026` + `refuelMonth=1..6` |
| 加氢车次 | 明细行数（一单一行） |
| 加氢总量 | `sum(amountKg)` |
| 平均加氢单价 | `sum(feeTotal) / sum(amountKg)`（含包氢等 0 单价单，会拉低均价） |
| 已核对 / 未核对 | `verifyStatus=verified` / 其他（本批全为 `unverified`） |

## 6. AI 路径

### 6.1 提示词（可复制）

```text
打开测试环境 https://dev-oneos.lnh2e.com 的车辆氢费明细。
汇总 2026 年 1–6 月：各加氢站的加氢车次数、加氢总量、平均加氢单价，以及已核对/未核对数量。
输出总览 + 分站表 + CSV。注明是测试环境数据。
```

### 6.2 步骤复原

| 步骤 | AI | 对应人工 |
|------|----|----------|
| 打开氢费明细 | 进 URL/菜单 | 点侧栏 |
| 按月拉 1–6 月明细 | refuelYear/Month | 分月筛选导出 |
| 按站点聚合车次/量/金额/核对 | 汇总 | Excel 透视 |
