# 物流自营条线 · 方案锁定假设

> 来源：物流条线业务模式方案（自营合同 × 轻量调度）  
> 锁定日期：2026-07-18  
> 用途：原型与 `.spec` 默认规则；下周访谈若推翻，改本文件并同步各规格。

## 已锁定默认

| 项 | 取值 | 说明 |
|---|---|---|
| 调度粒度 | 一车一次出车任务（可含多趟标记） | 非 TMS：无配载优化、无承运商招标、无复杂路径规划 |
| 合同对象 | 对客户的运力/物流服务合同 | 与租赁合同分模块；不做租期账单/押金/提车应收主路径 |
| 台账落点 | `self-operated-business-ledger`（物流业务明细） | 自动生成为主，导入/行编辑为补录 |
| 台账粒度 | **一任务一行** | 多趟用「是否多趟」字段标记，不按趟拆行 |
| 交还车 | 复用运维交还车能力（原型内用运营态模拟） | 不新建第二套交还车 |
| 办结前置 | **严格：车辆须已交车（运营态=自营）** | 未交车不可办结；可先「模拟交车」再办结 |
| 合同审批 | **轻量业务确认**（草稿→生效） | 不对齐租赁标准/非标法务全流程（一期） |
| 成本回填 | **一期仅自动带出营收侧字段** | 氢费/ETC/日成本等先手工或保持 0，增强包再自动 |
| 还车规则 | 还车时：未办结任务禁止还车；已办结台账行保留 | 原型演示「模拟还车」校验 |
| 一期边界 | 不做收款记录业财闭环 | 盈亏在台账内可算 |

## 访谈可推翻项（变更时同步代码与 PRD）

1. 办结是否允许「车未交车」  
2. 台账是否改为一趟一行 / 一日一车汇总  
3. 合同是否走租赁级审批  
4. 成本项一期是否自动带出氢费/ETC  
5. 还车是否强制关停未办结任务
