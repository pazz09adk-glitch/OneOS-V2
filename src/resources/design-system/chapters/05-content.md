# 05 · Content（文案、格式、状态词典）

---

## 1. 语气

- 简洁、中性、业务向；按钮用动词（查询、提交、通过）。
- 错误说明「是什么 + 怎么做」，避免只抛代码。
- 同一概念全站同词（如统一「重置」不混用「清空条件」除非场景不同）。

---

## 2. 日期时间

| 场景 | 格式 |
|------|------|
| 仅日期 | `YYYY-MM-DD` |
| 日期时间 | `YYYY-MM-DD HH:mm` |
| 含秒（日志） | `YYYY-MM-DD HH:mm:ss` |
| 日期区间展示 | `YYYY-MM-DD 至 YYYY-MM-DD` |

本版默认 **不展示时区**；跨时区需求在模块 `.spec` 声明。

---

## 3. 金额与数量

- 使用统一格式化（`src/common/format-number.js`）。
- 默认两位小数（业务另有规定除外）；千分位。
- 货币：`¥` 前缀或列头注明「元」，模块内统一。
- 表格内左对齐 + `tabular-nums`。

---

## 4. 空值

| 类型 | 展示 |
|------|------|
| 无文案/无值 | `-` |
| 业务「确实没有」 | `暂无`（如暂无备注） |
| 加载中 | Skeleton / `…` 不用 `-` 冒充 |

---

## 5. 长标识

| 类型 | 规则 |
|------|------|
| VIN | 可全量展示；窄列可截断中部 `…`，提供复制 |
| 车牌 | 不截断，统一使用标准中国车牌格式（如 `浙A88888F` 或 `沪B12345F`，禁止中间添加中圈点 `·` 或短横线） |
| 长单号 | 列表可截断尾部；详情全量 + 复制 |

---

## 6. 状态文案与 Tag 色

| 状态语义 | 文案示例 | Tag |
|----------|----------|-----|
| 草稿/待提交 | 待提交、草稿 | muted / 默认灰 |
| 进行中 | 审批中、处理中 | info / primary soft |
| 成功终态 | 已通过、已完成、已发布 | success |
| 警告 | 即将逾期、待补件 | warning |
| 失败/驳回 | 已驳回、已关闭、失败 | error |
| 停用 | 已停用、已作废 | muted |

禁止同一「已完成」在不同模块用不同颜色。新状态先补本表再上线。

---

## 7. 反馈文案模板

| 场景 | 示例 |
|------|------|
| 保存成功 | 保存成功 |
| 提交成功 | 提交成功 |
| 删除确认 | 确认删除「{名称}」？删除后不可恢复。 |
| 离开未保存 | 有未保存的更改，确定离开？ |
| 网络失败 | 网络异常，请稍后重试 |
| 校验失败 | 请完善标红的必填项 |

---

## 8. 空态三类

见 [04-patterns §6](./04-patterns.md)。标题短、说明一句、操作最多两个。

---

## Do / Don't

### Do

- 区间用中文「至」。
- 状态词与色一一对应并文档化。

### Don't

- 不要用「哎呀」「哦豁」等口语化错误标题。
- 不要在占位符写必填说明代替 label。
