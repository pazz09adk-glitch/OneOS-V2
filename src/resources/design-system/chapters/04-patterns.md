# 04 · Patterns（页面模式）

高频业务模式。列表细则与 `vm-shared` / 根规范 v1 对齐并扩展。

---

## 1. 列表 + 分页（Web）

### 1.1 结构

见 [02-layout §4.1](./02-layout.md)。类名：`vm-page` / `ldb-page` / `lc-page`。

### 1.1.1 行高（强制 · 对齐租赁合同）

| Token | 值 | 用途 |
|-------|-----|------|
| `--ln-table-cell-padding-y` | `16px` | 表体上下内边距 |
| `--ln-table-cell-padding-x` | `20px` | 表体左右内边距 |
| `--ln-table-row-min-height` | `87px` | 表体行高（含 padding） |
| `--ln-table-th-padding-y` | `14px` | 表头上下内边距 |
| `--ln-table-th-padding-x` | `20px` | 表头左右内边距 |

- 事实源：`oneos-ds-tokens.css`；可选 class `.ln-data-table`
- 母版：`lease-contract-management` 列表
- **禁止**各业务表私自压扁为 50px 级紧凑行

### 1.2 筛选

- 标题：「筛选条件」
- 操作右对齐：「重置」「查询」（查询为主按钮）
- 日期区间：`DateRangeFilterField` +「至」
- 折叠：`vm-filter-expand` + `splitFilterFields()`；禁止首行 5 项、展开末行仅 1 项
- **主入口视觉（强制）**：工具栏主搜索 +「更多筛选」使用 `V2FilterSearch` / `V2FilterMoreButton`（`.v2-filter-search` / `.v2-filter-more-btn`）；PC 高度 36px、圆角 8px 与旁侧按钮同高，靠主色浅底/描边/外晕引导点击；不得用弱 ghost 与导出同级，也不得私自改高度；PC 操作链单行（搜索可收缩，勿挤掉导入/列设置）；详见 `DESIGN.md` §2.4.3 / §2.4.3.2

### 1.3 工具栏

- 默认右对齐操作（导出、新建等）
- **禁止**在已有 KPI 或底部分页时重复「共 N 条」
- 允许：筛选开关、图例、批量操作

### 1.4 分页与数据行为

| 项 | 规则 |
|----|------|
| 形态 | 底部分页；默认禁止无限滚动（PRD 写明除外） |
| 排序 | 默认排序写清；切换排序重置到第 1 页（若影响稳定性） |
| 筛选 | 重置 `page = 1` |
| 批量 | 跨页勾选默认不保留（若保留须在 PRD 声明） |
| 导出 | Toast 可带条数；非常驻工具栏文案 |

参考：`src/prototypes/vm-shared/DESIGN.md`、`src/common/TablePagination.tsx`。

## 2. App / 小程序列表

| 项 | 规则 |
|----|------|
| 形态 | 行列表或卡片流 |
| 刷新 | 下拉刷新 |
| 分页 | 上拉加载更多 **或** 页码（二选一，模块内统一） |
| 加载 | 首屏 Skeleton；分页底部 spinner |
| 空态 | 插图 + 说明 + 可选引导按钮 |
| 错误 | 说明 +「重试」 |
| 左滑 | 非必须；若启用须有可见入口兜底；删除需确认 |

现场 H5 与小程序视觉走同一 Token（见 `field-theme.css`）。

## 3. 表单录入

| 项 | 规则 |
|----|------|
| 分组 | 区块标题 + 16–24 间距 |
| 必填 | 红色胶囊「必填」（`V2FieldLabel`）；提交时校验；禁止仅黑色 `*` |
| 选填 | 易误解字段挂灰色胶囊「选填」 |
| 默认值 | 合理预填；占位示例勿冒充已填 |
| App 键盘 | 数字/电话/邮箱类型正确；Return 键语义（下一项/完成） |
| 扫码填入 | 成功 Toast；失败可重扫 |
| 多步 | Steps + 可返回；返回未保存确认 |
| 附件 | 展示格式/大小/数量上限 |
| 成功 | Toast + 回列表或进详情（模块统一） |

---

## 4. 详情

- 摘要头展示状态 Tag + 关键 ID（可复制）。
- 长详情用 Tabs/锚点，避免单页无限堆叠无导航。
- 主操作：页头或底栏，不两处重复同等主按钮。

---

## 5. 审批

- 流程轴在表单之上或侧栏（宽屏）。
- 通过=主按钮；驳回=危险/次按钮并必填意见。
- 附件只读列表可预览。

---

## 6. 空态 / 权限 / 失败

| 场景 | 标题口径 | 操作 |
|------|----------|------|
| 无数据 | 「暂无数据」+ 可选筛选提示 | 清除筛选 / 新建 |
| 无权限 | 「暂无访问权限」 | 返回 |
| 加载失败 | 「加载失败」 | 重试 |

文案词典见 [05-content](./05-content.md)。

---

## 7. 搜索

- Web 全局搜索（若有）在顶栏；结果页复用列表模板。
- App SearchBar 在列表顶；历史与热词可选；清除一键可见。

---

## 8. 现场任务（验车等）

```text
任务信息 → 检查项列表 → 拍照/扫码 → 签名 → 提交结果
```

- 底栏单一主按钮（提交/下一步）。
- 主色与 Web 同源 `#533AFD`。
- 错误项用 error 色 + 文字，不单靠色块。

---

## Do / Don't

### Do

- 列表 Web 走 `TablePagination` + `OperationActions`。
- 模块内统一「分页」或「加载更多」，不混用。

### Don't

- 不要在工具栏与分页重复总条数。
- 不要让现场页另起绿色体系。
