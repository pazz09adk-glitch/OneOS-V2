# OneOS R1 用户故事清单（可排期）

> 来源：[user-story-map.md](./user-story-map.md) 中全部 **R1** 任务  
> 格式：作为…我想…以便… + 验收要点 + 原型 + 建议规模  
> 日期：2026-07-19  
> 说明：本清单用于排期；故事地图仍是战略真相源。原型已具备能力的条目标为「原型已覆盖」，排期侧重联调/验收/缺口补齐。

---

## 排期建议（R1 内五波）

| 波次 | 目标 | 建议故事 ID |
|------|------|-------------|
| **W1 签约底座** | 能建客户、有模板、能签租赁/自营并走审批 | US-01 ~ US-10 |
| **W2 收款交车** | 提车应收 → 认领到账 → 保险校验 → 交车 | US-11 ~ US-17 |
| **W3 履约记账** | 租赁台账/明细 + 自营调度办结落账 | US-18 ~ US-22 |
| **W4 能源结算** | 加氢采集 → 氢费核对 → 站点对账 | US-23 ~ US-27 |
| **W5 还车与督办** | 还车应结 + 维保/工单 + 工作台执行台 + 经营看数 | US-28 ~ US-40 |

依赖示意：

```text
W1 → W2 → W3 ─┬→ W4
               └→ W5（工作台可与 W1 并行启动壳层）
```

规模：`S` ≤3 人日 · `M` 3–8 人日 · `L` >8 人日（含联调/规则，按团队校准）

## Epic A · 建档与签约（Activity 1）

### US-01 筛选并识别客户风险
**作为** 业务员/业管，**我想** 按条件筛选客户并看到风险标签与 KPI，**以便** 签约前先识别高风险客户。  
- **验收**：多维筛选可用；风险标签与 KPI 与列表一致；可进入客户详情。  
- **原型**：`customer-management` · **规模**：M · **波次**：W1 · **状态**：原型已覆盖

### US-02 新建客户主数据
**作为** 业务员，**我想** 按集团/子公司规则新建客户，**以便** 后续合同与账单有正确主数据。  
- **验收**：编号规则正确；必填校验；保存后出现在列表。  
- **原型**：`customer-management` · **规模**：M · **波次**：W1

### US-03 维护供应商主数据
**作为** 采购/业管，**我想** 维护供应商及结算要素，**以便** 加氢站/采购等业务可引用。  
- **验收**：新增/编辑/筛选；结算关键字段可保存。  
- **原型**：`supplier-management` · **规模**：S · **波次**：W1

### US-04 导入并发布合同模板
**作为** 法务，**我想** 导入 Word 拆章节并发布启用模板，**以便** 业务员签约时选用标准文本。  
- **验收**：Word 导入成功；草稿→发布→启用；启用中模板不可误删。  
- **原型**：`contract-template-management` · **规模**：L · **波次**：W1

### US-05 配置模板变量与条件条款
**作为** 法务，**我想** 配置车型/付款方式等变量与条件条款，**以便** 不同车型合同自动适配条款。  
- **验收**：变量可插入预览；条件条款按车型生效。  
- **原型**：`contract-template-management` · **规模**：M · **波次**：W1

### US-06 浏览租赁合同台账 KPI
**作为** 业务员，**我想** 筛选合同列表并看到审批/合同状态 KPI，**以便** 掌握签约进度。  
- **验收**：筛选与 KPI 联动；点击可进详情。  
- **原型**：`lease-contract-management` · **规模**：S · **波次**：W1

### US-07 用标准模板新增并预览租赁合同
**作为** 业务员，**我想** 选用启用中模板新建租赁合同并预览，**以便** 快速发起标准签约。  
- **验收**：模板与合同字段联动；预览内容与模板一致；可保存草稿。  
- **原型**：`lease-contract-management` · **规模**：L · **波次**：W1

### US-08 提交租赁合同审批并由审批人处理
**作为** 业务员/审批人，**我想** 提交合同进入审批流并在审批中心处理，**以便** 合同合法生效。  
- **验收**：提交后出现在「我发起的」；审批人「我的待办」可见；通过/驳回状态回写合同。  
- **原型**：`lease-contract-management` + `oneos-web-approval-*` · **规模**：L · **波次**：W1

### US-09 创建并生效自营合同
**作为** 业务管理组，**我想** 创建自营合同草稿并业务确认生效，**以便** 后续可被调度选用。  
- **验收**：草稿→生效；生效后状态 KPI 正确；未生效不可被调度选用。  
- **原型**：`self-operated-contract` · **规模**：M · **波次**：W1

### US-10 维护自营合同履约要素
**作为** 业务服务组，**我想** 维护客户、车型数量、交车点、单价与附件，**以便** 调度与台账有依据。  
- **验收**：关键字段可保存；附件可上传；列表可检索。  
- **原型**：`self-operated-contract` · **规模**：S · **波次**：W1

## Epic B · 收款与交车（Activity 2）

### US-11 查看提车应收与车辆明细
**作为** 业务员，**我想** 在合同提交后看到提车应收单及车辆明细，**以便** 知道客户该付多少。  
- **验收**：合同提交自动/可生成应收；车辆明细完整；金额可读。  
- **原型**：`vehicle-pickup-receivable` · **规模**：M · **波次**：W2

### US-12 按规则核对提车应收金额
**作为** 业务员/财务，**我想** 按提车日规则核对应收（保证金+租金服务费），**以便** 收费不错算。  
- **验收**：规则说明可见；金额与规则一致；异常可标出。  
- **原型**：`vehicle-pickup-receivable` · **规模**：M · **波次**：W2

### US-13 登记到账并查看未关联预警
**作为** 财务/业管，**我想** 录入或导入到账并看到未关联预警，**以便** 及时发现未认领款项。  
- **验收**：列表 KPI 含未关联；导入成功；工作台可消费同一预警源。  
- **原型**：`payment-records` · **规模**：M · **波次**：W2

### US-14 收款认领关联业务账单
**作为** 财务/业管，**我想** 将收款关联到租赁/自营/氢费账单，**以便** 台账实收对齐。  
- **验收**：多选关联；关联后账单/台账状态更新；可追溯。  
- **原型**：`payment-records` · **规模**：L · **波次**：W2

### US-15 交车前确认车辆资产状态
**作为** 运维/业务，**我想** 在车辆资产中确认运营状态与项目合同，**以便** 只对可交车车辆执行交付。  
- **验收**：状态/合同/保险到期信息可见；不可交车原因可理解。  
- **原型**：`vehicle-management` · **规模**：S · **波次**：W2

### US-16 执行交车任务
**作为** 运维，**我想** 在运维流程中完成交车，**以便** 车辆进入履约运营。  
- **验收**：交车后车辆运营状态更新；租赁/自营链路可继续记账或调度。  
- **原型**：`oneos-web-ops` · **规模**：L · **波次**：W2

### US-17 保险有效才允许交车
**作为** 采购/运维，**我想** 维护交强+商业险台账并在交车时校验有效，**以便** 不合规车辆无法交车。  
- **验收**：险种台账可维护；交车校验拦截无效保单；提示明确。  
- **原型**：`insurance-procurement` · **规模**：M · **波次**：W2

## Epic C · 履约运营与能源（Activity 3）

### US-18 维护租赁业务台账并关联收款
**作为** 租赁客服，**我想** 按月筛选台账、看 KPI 并关联收款，**以便** 掌握应收实收。  
- **验收**：筛选/KPI/关联收款可用；权限区分员工/主管。  
- **原型**：`lease-business-ledger` · **规模**：M · **波次**：W3

### US-19 核对租赁业务明细宽表与系统校验
**作为** 业管，**我想** 在明细宽表中核对公式列与系统校验，**以便** 导入/手工数据符合规则。  
- **验收**：公式列自动算；校验提示可见；表尾汇总正确。  
- **原型**：`lease-business-detail` · **规模**：L · **波次**：W3

### US-20 创建调度任务并派车
**作为** 调度岗，**我想** 选择已生效自营合同创建任务并派车，**以便** 组织出车。  
- **验收**：仅生效合同可选；派车后状态进入已派/执行中。  
- **原型**：`self-operated-dispatch-task` · **规模**：M · **波次**：W3

### US-21 办结出车并自动生成物流明细
**作为** 调度岗，**我想** 办结出车后自动生成物流业务明细一行，**以便** 少手工记账。  
- **验收**：办结成功；台账行含任务号；金额/成本可核算。  
- **原型**：`self-operated-dispatch-task` + `self-operated-business-ledger` · **规模**：M · **波次**：W3

### US-22 （可与 W3 并行）自营合同未生效不可调度
*验收并入 US-09/US-20，不单独立项。*

### US-23 H5 上报本站加氢流水
**作为** 加氢站操作员，**我想** 在手机上新增加氢记录（含手工台账照片），**以便** 及时上报本站流水。  
- **验收**：本站列表+新增；照片可传；与 Web 同源可见。  
- **原型**：`oneos-h5-h2-order` · **规模**：L · **波次**：W4

### US-24 Web 管理多站加氢记录
**作为** 能源组，**我想** 在 PC 多站查看、导入导出加氢记录，**以便** 集中核对。  
- **验收**：多站筛选；导入导出；详情原图。  
- **原型**：`oneos-web-h2-station` · **规模**：M · **波次**：W4

### US-25 核对车辆氢费异常
**作为** 能源组业务员，**我想** 在氢费明细中标出量/单价异常并完成核对，**以便** 对账前数据可靠。  
- **验收**：异常标黄；核对状态可推进；已对账不可被业务员误改。  
- **原型**：`vehicle-h2-fee-ledger` · **规模**：M · **波次**：W4

### US-26 站点对账单结算闭环
**作为** 加氢站运营/结算，**我想** 按站生成对账单、收票并提交结算，**以便** 完成能源结算。  
- **验收**：对账单生成；收票→提交；氢费回写已对账。  
- **原型**：`oneos-web-h2-station-site` · **规模**：L · **波次**：W4

### US-27 （可选 W4）站点价格与预付余额维护  
并入 US-26 验收范围或拆子任务，**规模**：S。

## Epic D · 运维异常与还车（Activity 4）

### US-28 总览车辆证照保险交还车状态
**作为** 运维/业务，**我想** 在车辆资产一览证照、保险与交还车状态，**以便** 发现到期与异常车。  
- **验收**：KPI/筛选可用；到期信息可见。  
- **原型**：`vehicle-management` · **规模**：S · **波次**：W5（可与 W2 并行）

### US-29 录入维保台账并提交归档
**作为** 运维，**我想** 录入维保费用并确认提交、可导出，**以便** 成本可追溯。  
- **验收**：新增→保存→提交；本人数据范围；导出成功。  
- **原型**：`vehicle-maintenance-ledger` · **规模**：M · **波次**：W5

### US-30 创建并指派任务工单
**作为** 业管，**我想** 从合同拆解或独立创建工单并指派，**以便** 督办运维执行。  
- **验收**：可绑车与周期；指派后执行人可见任务（金额脱敏规则按 PRD）。  
- **原型**：`task-work-order` · **规模**：M · **波次**：W5

### US-31 还车后生成应结并分部门填费用
**作为** 业管/安全/运维/能源，**我想** 还车后收到应结任务并填本部门费用，**以便** 算清应退应补。  
- **验收**：任务自动生成；分部门可填；汇总可见。  
- **原型**：`vehicle-return-settlement` · **规模**：L · **波次**：W5

### US-32 还车应结关联收付并审批归档
**作为** 业管/财务，**我想** 关联收款或付款并走总审批归档，**以便** 还车财务闭环。  
- **验收**：可关联收付；审批通过后归档；状态不可回退（按 PRD）。  
- **原型**：`vehicle-return-settlement` + 审批 · **规模**：M · **波次**：W5

## Epic E · 工作台督办与经营洞察（Activity 5）

### US-33 按角色查看预警 KPI
**作为** 各岗位用户，**我想** 打开工作台看到本角色预警指标，**以便** 先处理高风险事项。  
- **验收**：角色切换 KPI 变化；点击打开明细；含收款未关联等已定指标。  
- **原型**：`oneos-web-workbench-new` · **规模**：M · **波次**：W5（壳层可 W1 并行）

### US-34 按待办三态执行工作
**作为** 业务员，**我想** 按「异常 / 今日必办 / 即将执行」处理待办并看到当前步骤，**以便** 当天清掉该办的事。  
- **验收**：三态互斥计数正确；默认优先异常；当前步骤列展示 flow.current；可跳转办理。  
- **原型**：`oneos-web-workbench-new` 方案 C · **规模**：L · **波次**：W5

### US-35 阅知通知并跳转办理
**作为** 业务员，**我想** 只看未读通知且催办优先，点开即可办理，**以便** 不漏重要消息。  
- **验收**：仅未读；催办优先；空态文案；可跳转任务/页面。  
- **原型**：`oneos-web-workbench-new` · **规模**：M · **波次**：W5

### US-36 在审批中心处理四类审批
**作为** 审批相关人员，**我想** 在「发起/待办/已办/抄送」中处理审批，**以便** 流程不堵。  
- **验收**：四 Tab 计数正确；类型筛选；详情可操作。  
- **原型**：`oneos-web-approval-*` · **规模**：M · **波次**：W1/W5

### US-37 工作台查看审批当前步骤
**作为** 业务员，**我想** 在工作台看到审批卡在哪一步、谁在处理，**以便** 决定催办或等待。  
- **验收**：展示当前步骤文案 + 处理人；可进完整审批页。  
- **原型**：`oneos-web-workbench-new` · **规模**：S · **波次**：W5

### US-38 自定义常用功能入口
**作为** 业务员，**我想** 钉选并排序常用入口，**以便** 快速发起或进入模块。  
- **验收**：钉选持久化（按角色）；排序可用；点击跳转/发起正确。  
- **原型**：`oneos-web-workbench-new` · **规模**：M · **波次**：W5

### US-39 从工作台快速发起常用业务
**作为** 业务员，**我想** 一键发起新合同/退车/保险/充值等，**以便** 少找菜单。  
- **验收**：各发起动作有确认/跳转；无权限项不展示。  
- **原型**：工作台 + 各业务页 · **规模**：M · **波次**：W5

### US-40 查看角色洞察与经营分析
**作为** 业务员/管理层，**我想** 查看角色业务洞察及项目盈亏、客户回款，**以便** 做经营判断。  
- **验收**：洞察随角色变；盈亏/回款页可打开且数据口径有说明。  
- **原型**：`oneos-web-workbench-new` + `business-dept-ledger` + `customer-payment-collection` · **规模**：M · **波次**：W5
