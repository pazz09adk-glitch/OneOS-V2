# 底座 · 车辆资产台账

**一句话**：一车一档，承载状态、证照、保险、停放、运维指派与全生命周期事件；PC 台账 + H5 只读查车。

## 关键口径（摘要）

- 运营状态五档：租赁 / 物流 / 在库-可交付 / 在库-不可交付 / 退出运营。
- 履约中不展示在库停车场语义；运维匹配看最后停放区域。
- 保险：交强/商业分行；异常/临期（30 天）/正常；临期不阻断交车。
- 沪牌证照状态特例：按等级评定时间，不看行驶证检验有效期。
- 编辑档案正式环境仅 Admin。
