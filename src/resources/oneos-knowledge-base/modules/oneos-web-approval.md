# 审批中心

| 项 | 内容 |
|---|---|
| 模块 ID | `oneos-web-approval` |
| 条线 | platform |
| 责任部门 | 各审批角色 |
| 置信度 | 已定稿（`confirmed`） |

## 页面说明

- **待办/已办/发起**：办理待办、追溯发起、多业务同壳

## 角色与权限

| 角色 | 权限要点 |
|------|----------|
| 审批人 | — |
| 发起人 | — |

## 起点 → 运作 → 闭环

- **起点**：收到待办或查看发起
- **怎么运作**：见下方操作说明与正向步骤。
- **闭环**：审批结论回写源业务单据

## 前置条件

- 业务单据提交审批

## 操作说明（主路径）

1. 打开待办
2. 同意/驳回/转办（按壳能力）
3. 回写业务单据状态

## 业务规则

- 多业务同壳
- 标题与编号规范
- 办结必须回写源单

## 正向 / 逆向

**正向**（摘要同上操作说明）

**逆向 / 边界**

| 情况 | 系统表现 |
|------|----------|
| 已办结再改 | 按业务规则禁止或走冲销 |
| 无权限 | 不可见或只读 |

## 禁止与边界

- 壳内办结与源单状态不一致

## 关联与触发

- （无额外触发）
