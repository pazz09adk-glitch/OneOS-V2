# 客户对接过程管理

| 项 | 内容 |
|---|---|
| 模块 ID | `customer-engagement` |
| 条线 | lease |
| 责任部门 | 业务管理组 / 业务主管 |
| 置信度 | 架构推导 · 待原型校验（`architecture`） |

## 页面说明

- **对接台账**：按状态分流的对接单列表（仅列表，无看板/主从）
- **对接详情**：跟进时间线、准入衔接、转让/延期、发起合同门禁演示

## 角色与权限

| 角色 | 权限要点 |
|------|----------|
| 业务员 | 认领、跟进、催准入、本人有效单内建合同 |
| 业务主管 / 业管 | 仲裁撞单、审批转让与延期、强制变更归属 |

## 起点 → 运作 → 闭环

- **起点**：命中或新建客户主体并发起认领
- **怎么运作**：主体独占校验 → 跟进过程 → 推进准入 → 仅归属人建合同；保护到期释放；转让审批变更归属
- **闭环**：合同生效 → 对接单已转化并快照业绩归属；失败或释放可再进入认领池

## 前置条件

- 企业客户具备统一社会信用代码（个人客户具备证件号）
- 建合同另需客户准入允许

## 操作说明（主路径）

1. 按主体发起对接认领（撞单则拦截）
2. 登记跟进；催办/发起客户准入
3. 准入标准/非标后，归属人发起租赁合同
4. 合同生效 → 对接单已转化；或保护到期释放 / 准入禁止关单

## 业务规则

- **一主体同时仅一名主对接人**；协作人只读、不可抢建合同
- **可先认领再准入**；建合同必须准入通过
- 保护期默认 **30 自然日**，可延期一次（主管批）
- 建合同门禁：`准入允许` AND `对接有效且操作人=主对接人`
- 业绩：合同生效时快照主对接人
- **业财基准**：资金门禁仍从合同生效后算，本模块不改收款核销

## 正向 / 逆向

**逆向 / 边界**

| 情况 | 系统表现 |
|------|----------|
| 同主体二次认领 | 拦截并展示归属人与保护期 |
| 无对接单建合同 | 拦截（历史豁免名单一期另维） |
| 非归属人建合同 | 拦截 |
| 准入禁止 | 不可建合同；可关单失败 |
| 保护到期 | 自动释放，可被再认领 |

## 禁止与边界

- 不做通用公海积分 / 营销自动化（一期）
- 不把跟进记录当收付款凭证
- 断头对接单（无归属悬挂）

## 关联与触发

- ↔ **customer-management**：绑定主体；读/催办准入
- → **lease-contract-management**：新建合同前置对接归属校验
- → **oneos-web-workbench-new**：保护将尽 / 待准入 / 待转让催办
- → **analytics-business-ledgers** / 业务部业绩：生效快照归属人
- → **biz-finance-integration**：下游业财不变
