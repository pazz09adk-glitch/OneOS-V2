# 验车入库

| 项 | 内容 |
|---|---|
| 模块 ID | `vehicle-inspection` |
| 条线 | ops |
| 责任部门 | 运维 |
| 置信度 | 已定稿（`confirmed`） |

## 页面说明

- **验车任务/表单**：现场核对，验完标记库存入库

## 角色与权限

| 角色 | 权限要点 |
|------|----------|
| 运维 | — |

## 起点 → 运作 → 闭环

- **起点**：接收验车任务
- **怎么运作**：见下方操作说明与正向步骤。
- **闭环**：验车通过并进入库存车辆

## 前置条件

- 采购侧验车任务已下发

## 操作说明（主路径）

1. 现场核对车辆识别代码与配置
2. 提交验车结果
3. 自动标记库存

## 业务规则

- 车辆识别代码入库主键

## 正向 / 逆向

**正向**（摘要同上操作说明）

**逆向 / 边界**

| 情况 | 系统表现 |
|------|----------|
| 验车不合格 | 不入库或退回采购处理 |

## 禁止与边界

- 跳过验车直接上牌运营

## 关联与触发

- → **vehicle-management**：档案入库
- → **oneos-web-ops**：进入上牌证照备车
