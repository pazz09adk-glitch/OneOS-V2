# 保险采购

| 项 | 内容 |
|---|---|
| 模块 ID | `insurance-procurement` |
| 条线 | ops |
| 责任部门 | 采购 / 运维 / 安全 |
| 置信度 | 已定稿（`confirmed`） |

## 页面说明

- **保单台账**：一车一档保单检索、录入、停保复驶退保留痕

## 角色与权限

| 角色 | 权限要点 |
|------|----------|
| 采购 | — |
| 运维 | — |

## 起点 → 运作 → 闭环

- **起点**：新车交车合规或续保/停复驶
- **怎么运作**：见下方操作说明与正向步骤。
- **闭环**：保单有效并回写车辆保险列

## 前置条件

- 车辆档案存在

## 操作说明（主路径）

1. 检索车辆保单
2. 多通道录入正式保单
3. 停保/复驶/退保留痕
4. 回写资产保险状态

## 业务规则

- 交车合规关注在保状态
- 变更必须留痕
- **业财规划**：比价与保单材料可并行；比价审批通过后**自动生成保险付款申请/付款任务**（带供应商账户打款信息）→ 财务付款并关联保险付款单闭环 → 方可**批量上传保单**、系统自动识别、**一车多保**
- **业财基准**：[biz-finance-integration](../foundations/biz-finance-integration.md)

## 正向 / 逆向

**正向**（摘要同上操作说明）

**逆向 / 边界**

| 情况 | 系统表现 |
|------|----------|
| 交强或商业缺失/过期 | 资产侧保险异常 |
| 临期 | 提示关注不阻断交车 |
| 付款未闭环 | 不可批量正式归档保单 |

## 禁止与边界

- 无留痕直接改保单状态
- 未付款闭环即批量正式归档保单

## 关联与触发

- → **vehicle-management**：保险状态回写
- → **supplier-management**：保险公司账户信息
- → **payment-records**：保险付款关联
- → **biz-finance-integration**：全链条业财门禁
