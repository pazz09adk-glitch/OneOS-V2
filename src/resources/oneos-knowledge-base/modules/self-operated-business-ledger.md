# 物流业务明细 / 项目盈亏

| 项 | 内容 |
|---|---|
| 模块 ID | `self-operated-business-ledger` |
| 条线 | logistics |
| 责任部门 | 业务 / 财务 / 能源 |
| 置信度 | 架构推导 · 待校验（`architecture`） |

## 页面说明

- **物流台账**：办结落账、氢费/ETC 补录
- **项目盈亏**：收入成本汇总与钻取

## 角色与权限

| 角色 | 权限要点 |
|------|----------|
| 业务员 | — |
| 财务 | — |
| 能源 | — |

## 起点 → 运作 → 闭环

- **起点**：办结出车落账
- **怎么运作**：见下方操作说明与正向步骤。
- **闭环**：明细落账、盈亏可解释、收款可核销

## 前置条件

- 调度办结或成本补录发生

## 操作说明（主路径）

1. 查看业务明细
2. 补录氢费/ETC
3. 计算项目盈亏
4. 关联收款核销

## 业务规则

- 氢费/ETC 可补录进成本
- 关联财务收款

## 正向 / 逆向

**正向**（摘要同上操作说明）

**逆向 / 边界**

| 情况 | 系统表现 |
|------|----------|
| 缺成本补录 | 盈亏不完整提示 |
| 未关联收款 | 营收未闭环 |

## 禁止与边界

- 盈亏与台账脱节长期不核销

## 关联与触发

- → **business-dept-ledger**：汇总盈亏
- → **payment-records**：关联收款
