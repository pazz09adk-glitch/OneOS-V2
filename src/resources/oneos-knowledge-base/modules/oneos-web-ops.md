# 车辆运维综合

| 项 | 内容 |
|---|---|
| 模块 ID | `oneos-web-ops` |
| 条线 | ops |
| 责任部门 | 运维部 |
| 置信度 | 架构推导 · 待校验（`architecture`） |

## 页面说明

- **运维工作台/任务**：上牌、证照、备车、交还车、替换、年审、调拨等

## 角色与权限

| 角色 | 权限要点 |
|------|----------|
| 运维 | — |
| 区域运维 | — |

## 起点 → 运作 → 闭环

- **起点**：库存车进入上牌/证照/备车或履约任务
- **怎么运作**：见下方操作说明与正向步骤。
- **闭环**：任务办结并回写车辆状态与生命周期事件

## 前置条件

- 车辆已入库或处于对应任务态

## 操作说明（主路径）

1. 上牌录入车牌
2. 证照维护与临期待办
3. 备车整备
4. 交车（派单/培训/电子签）
5. 还车现场对比
6. 异动调拨替换

## 业务规则

- 区域权限流转见跨切规则
- 交还车关键节点可要求电子签
- 临期证照自动推送待办

## 正向 / 逆向

**正向**（摘要同上操作说明）

**逆向 / 边界**

| 情况 | 系统表现 |
|------|----------|
| 未备车 | 不可按可交付交车 |
| 提车款未对齐 | 交车任务不可办结（租赁路径） |
| 未交车 | 物流调度不可办结出车 |

## 禁止与边界

- 履约中按实时地理位置改运维区域

## 关联与触发

- → **vehicle-management**：状态与事件回写
- → **lease-business-ledger**：交车成功生成台账
- → **vehicle-return-settlement**：还车后发起应结
