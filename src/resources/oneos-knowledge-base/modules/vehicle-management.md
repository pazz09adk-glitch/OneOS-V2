## 起点 → 运作 → 闭环

- **闭环**：档案准确可查；处置类审批归档后退出运营路径完成

## 前置条件



## 操作说明（主路径）

1. 分类与筛选查车
2. 点车牌进详情
3. 查看证照保险里程
4. Admin 编辑档案（正式环境）
5. 处置出售/过户/报废审批归档

## 业务规则

- 运营状态五档
- 保险异常/临期30天/正常；临期不阻断交车
- 运维匹配依据最后停放区域
- 里程政策考核≠合同考核

## 正向 / 逆向

**正向**（摘要同上操作说明）

**逆向 / 边界**

| 情况 | 系统表现 |
|------|----------|
| 筛选无命中 | 空态暂无匹配车辆 |
| 履约中 | 停放展示车辆未在库 |
| 非 Admin 改档案 | 正式环境不可见/拦截编辑 |
| 沪牌证照 | 状态按等级评定时间特例 |

## 禁止与边界

- 车牌带间隔点
- 以原型演示入口当作全员可编辑档案
