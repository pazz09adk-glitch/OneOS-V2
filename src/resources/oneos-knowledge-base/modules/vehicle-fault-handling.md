# 故障处置（PC）

| 项 | 内容 |
|---|---|
| 模块 ID | `vehicle-fault-handling` |
| 条线 | ops |
| 责任部门 | 运维 |
| 置信度 | 已定稿（`confirmed`） |

## 页面说明

- **故障台账三视角**：列表/看板/主从督办
- **处置/详情全页**：处置、挂起、催办、证据链归档

## 角色与权限

| 角色 | 权限要点 |
|------|----------|
| 运维专员 | — |

## 起点 → 运作 → 闭环

- **起点**：故障单进入台账（含 AI/微信助手等上报）
- **怎么运作**：见下方操作说明与正向步骤。
- **闭环**：归档完成，生命周期可回写故障事件

## 前置条件

- 故障已上报入库

## 操作说明（主路径）

1. 筛选定位
2. 处置填写与证据
3. 必要时挂起/催办
4. 附件与地点齐备后归档

## 业务规则

- 上报后 30 天处置时限
- 归档硬门槛
- 详情全页非抽屉

## 正向 / 逆向

**正向**（摘要同上操作说明）

**逆向 / 边界**

| 情况 | 系统表现 |
|------|----------|
| 已挂起 | 不计剩余时限；展示挂起暂停中 |
| 归档缺附件或地点 | 硬拦截提示 |
| 超 30 天未处置 | 临期/逾期辅文告警（非挂起时） |

## 禁止与边界

- 无证据链强制归档

## 关联与触发

- → **vehicle-management**：故障事件上链
- → **oneos-v2-h5-vehicle-fault-handling**：移动端同口径
