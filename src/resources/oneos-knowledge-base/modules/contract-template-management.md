# 标准合同模板

| 项 | 内容 |
|---|---|
| 模块 ID | `contract-template-management` |
| 条线 | lease |
| 责任部门 | 法务 / 业务管理组 |
| 置信度 | 架构推导 · 待校验（`architecture`） |

## 页面说明

- **模板库**：维护法务标准制式合同、锁定区、风控红线、品牌/车型条件条款与附件
- **模板选用**：签约时选择模板并填写非锁定区

## 角色与权限

| 角色 | 权限要点 |
|------|----------|
| 法务 | 维护制式合同、红线、锁定区、车型条件条款/附件 |
| 业务员 | 选用已发布模板；不可擅自改锁定区与红线 |

## 起点 → 运作 → 闭环

- **起点**：法务形成并维护标准制式化合同
- **怎么运作**：配置红线、按品牌/车型可见的条款与附件、锁定不可修改区域；发布后供租赁合同调取
- **闭环**：有效模板可被租赁合同引用；触红线/改红线由租赁合同侧进非标审批

## 前置条件

- 模板已发布且版本有效

## 操作说明（主路径）

1. 创建/修订标准制式合同
2. 配置风控红线、品牌/车型可见条款与附件、锁定区
3. 发布版本
4. 业务创建租赁合同时调取

## 业务规则

- 锁定区不可被业务随意改写
- 风控红线可维护；改动或触及在租赁合同侧触发非标
- 可按部分品牌、车型设置可见条款与附件
- **业财/规划基准**：[biz-finance-integration](../foundations/biz-finance-integration.md)

## 正向 / 逆向

**正向**（摘要同上操作说明）

**逆向 / 边界**

| 情况 | 系统表现 |
|------|----------|
| 触碰/改动风控红线 | 租赁合同转非标审批 |
| 改锁定区 | 禁止或需法务权限 |

## 禁止与边界

- 业务绕过模板直接生成无版本合同

## 关联与触发

- → **lease-contract-management**：签约选用模板
- → **biz-finance-integration**：全链条规划基准
