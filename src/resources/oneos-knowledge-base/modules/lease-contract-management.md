# 租赁合同

| 项 | 内容 |
|---|---|
| 模块 ID | `lease-contract-management` |
| 条线 | lease |
| 责任部门 | 业务管理组 / 法务 |
| 置信度 | 已定稿 + 规划补充（`confirmed`，签章/编号唯一等见规划基准） |

## 页面说明

- **列表/看板/主从**：同页三视角管理合同与车辆子表
- **合同详情/表单**：标准/非标路径、签章、附件回传

## 角色与权限

| 角色 | 权限要点 |
|------|----------|
| 业务员 / 业管 | 调取模板建合同、跟非标、发起签章/分享 |
| 法务 | 标准模板；线下盖章回传后补附件；催办协同 |
| 业务主管 | 非标审批相关 |

## 起点 → 运作 → 闭环

- **起点**：客户准入允许 + 调取有效标准合同模板
- **怎么运作**：按模板红线/车型条款/锁定区填写；改红线或新增内容自动非标审批；编号自动唯一；合同即规则锁死履约要素；E 签宝或线下盖章回传
- **闭环**：签章/法务附件齐备 → 合同生效 → 驱动提车应收、账单、还车应结、里程等；未闭环则工作台催办常驻

## 前置条件

- 客户准入允许
- 选用有效标准合同模板

## 操作说明（主路径）

1. 调取标准合同模板，填写合同要素与车辆
2. 触红线或新增内容 → 非标审批
3. 系统生成唯一合同编号（消除历史重复）
4. 线上：在线打印 + E 签宝公司章/客户章；或线下：分享链接/不可篡改文件 → 客户盖章 → 法务补附件
5. 生效后履约准备（提车应收等按本合同规则生成）

## 业务规则

- **合同即规则 · 一对一锁死**：条款与标准合同锁死；提车应收、租赁账单、还车应结、里程要求等关键要素均由本份合同驱动，不可另起口径
- 改风控红线或新增合同内容 → 自动非标审批
- 编号自动化且必须唯一（现存重复为待治理问题）
- 支持在线打印；E 签宝在线自动签章；客户登录 E 签宝签客户章
- 不愿线上签：分享链接或不可篡改文件 → 线下盖章回传法务 → 法务补附件闭环
- 未闭环：工作台催办任务持续存在
- **业财/规划基准**：[biz-finance-integration](../foundations/biz-finance-integration.md)

## 正向 / 逆向

**正向**（摘要同上操作说明）

**逆向 / 边界**

| 情况 | 系统表现 |
|------|----------|
| 禁止签约客户 | 拦截 |
| 非标未通过 | 不可生效 |
| 签章/附件未闭环 | 工作台催办常驻；不可当已生效履约 |
| 编号冲突 | 拦截生成（规划） |

## 禁止与边界

- 未生效/未签章闭环合同触发交车任务
- 绕过模板或锁定区不进非标
- 编号重复入库

## 关联与触发

- ← **contract-template-management**：调取模板
- → **vehicle-pickup-receivable**：生效后产生提车应收
- → **lease-business-ledger**：账单与里程规则
- → **vehicle-return-settlement**：还车应结规则
- → **oneos-web-workbench-new** / 工作台：签章未闭环催办
- → **biz-finance-integration**：全链条规划基准
