# 加氢订单（H5）

| 项 | 内容 |
|---|---|
| 模块 ID | `oneos-h5-h2-order` |
| 条线 | energy |
| 责任部门 | 加氢站操作员 / 能源部 |
| 置信度 | 架构推导 · 待校验（`architecture`） |

## 页面说明

- **H5 加氢订单**：签约站主动上报、预约；PLC 自动采集入库

## 角色与权限

| 角色 | 权限要点 |
|------|----------|
| 加氢站操作员 | — |
| 能源 | — |

## 起点 → 运作 → 闭环

- **起点**：站端发起加氢或 PLC 采集
- **怎么运作**：见下方操作说明与正向步骤。
- **闭环**：加氢记录进入可对账状态

## 前置条件

- 签约站与账号有效

## 操作说明（主路径）

1. 录入/上报加氢量与车辆
2. 生成加氢记录
3. 进入能源对账池

## 业务规则

- 主动上报与 PLC 均可入库
- 记录需可对账

## 正向 / 逆向

**正向**（摘要同上操作说明）

**逆向 / 边界**

| 情况 | 系统表现 |
|------|----------|
| 账号无效 | 不可上报 |
| PLC 失败 | 可人工补报或告警 |

## 禁止与边界

- 无车辆关联的孤儿流水长期悬挂

## 关联与触发

- → **vehicle-h2-fee-ledger**：记录汇入明细
- → **payment-records**：对账后核销
