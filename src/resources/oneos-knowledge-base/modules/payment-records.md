# 收款记录 / 氢费账户

| 项 | 内容 |
|---|---|
| 模块 ID | `payment-records` |
| 条线 | energy |
| 责任部门 | 财务 / 能源 / 业务 |
| 置信度 | 架构推导 · 待校验（`architecture`） |

## 页面说明

- **收款/付款记录**：业财对接面：流水、认领、核销
- **客户氢费账户/对账单**：预付款与加氢对账关联收款

## 角色与权限

| 角色 | 权限要点 |
|------|----------|
| 财务 | — |
| 能源 | — |
| 业务 | — |

## 起点 → 运作 → 闭环

- **起点**：业务对账单或财务流水进入
- **怎么运作**：见下方操作说明与正向步骤。
- **闭环**：业务单据回写已付款/已实收且资金记录一致

## 前置条件

- 存在业务应收/应付或预付款

## 操作说明（主路径）

1. 关联业务单据
2. 财务确认到账/出账
3. 回写业务已实收/已付款

## 业务规则

- 收款流与付款流分列
- 双向核销与状态回写
- 可服务租赁/能源/物流/还车/保险等多条线
- 收款关联：提车应收、租赁账单、还车应收、能源充值/氢气预付、客户氢费对账单
- 付款关联：还车应退、加氢站对账单、保险付款单
- 能源：关联收款后充入账户；已核对后扣费
- **业财基准**：[biz-finance-integration](../foundations/biz-finance-integration.md)

## 正向 / 逆向

**正向**（摘要同上操作说明）

**逆向 / 边界**

| 情况 | 系统表现 |
|------|----------|
| 金额不匹配 | 不可完成核销 |
| 取消关联 | 回退业务付款标记（按规则） |

## 禁止与边界

- 只改业务状态不留资金痕迹
- 无关联假性结清/已充值/已付款

## 关联与触发

- → **lease-business-ledger**：租期账单核销
- → **vehicle-pickup-receivable**：提车收款对齐
- → **vehicle-return-settlement**：还车收/付
- → **vehicle-h2-fee-ledger**：加氢已付款回写
- → **insurance-procurement**：保险付款
- → **biz-finance-integration**：全链条业财门禁
