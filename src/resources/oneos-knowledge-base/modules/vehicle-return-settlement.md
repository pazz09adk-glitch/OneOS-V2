## 起点 → 运作 → 闭环

- **起点**：还车完成后发起应结会签
- **怎么运作**：见下方操作说明与正向步骤。
- **闭环**：会签通过且收付款核销完成并归档

## 前置条件

- 运维完成还车节点

## 操作说明（主路径）

1. 各部门填写费用段
2. 运维可转交办理人（原因必填）
3. 提交审批
4. 补缴/退还关联收付款
5. 归档

## 业务规则

- 转交只换办理人不改费用与审批流
- 主管可代转
- 多部门会签齐备才可资金闭环
- **单据生成后**：安全板块按车辆 + 本段实际交还车周期自动只读展示违章/事故，不依赖安全员本单提交；无记录文案为「暂无违章记录」
- **无忧包核算**（收费方案终版）：是否购买由业管与客户谈妥反写；养护保＝里程×元/公里；易损保＝计费月数×月费（不含轮胎、漆面、玻璃）；未购买不计费
- **无忧包减免**：未结算保养/维修/轮胎磨损分别挂钩养护保/易损保/轮胎保；未购则减免禁用；减免计入业务成本
- **退租日**：还车成功且 E 签宝用户方签字完成 = 实际退租日；预付提前还车可应退
- **费用源（业财规划）**：ETC（自动或登记；卡/设备损坏责任待拍板）；能源氢量差补缴；运维未结保养/维修/工具/证照/送接车/胎纹；广告损坏单价待定；安全未在账单闭环的费用并入尾期
- **业财基准**：[biz-finance-integration](../foundations/biz-finance-integration.md)

## 正向 / 逆向

**正向**（摘要同上操作说明）

**逆向 / 边界**

| 情况 | 系统表现 |
|------|----------|
| 审批中 | 费用明细可查看；运维段只读仍可转交；不改审批流 |
| 审批完成后 | 无转交图标 |
| 转给自己或非运维 | 拦截 |
| 原因为空 | 不可提交转交 |
| 安全员尚未提交本单 | 仍展示自动带出的本段违章/事故或「暂无违章记录」 |
| 租期外历史违章/事故 | 不展示 |
| 未购买无忧包 | 自动核算为 0；对应减免禁用 |
| 车型不在收费方案 | 提示未配置，费用为 0 |
| 应退未付 | 须付款记录关联后闭环 |

## 禁止与边界

- 审批完成后改关键费用无冲销
- 其他部门转交（本期非目标）
- 在应结单内手工改无忧包单价（改费率走收费方案主数据）
- 无收/付款关联假性结清

## 关联与触发

- → **oneos-web-approval**：进入审批壳
