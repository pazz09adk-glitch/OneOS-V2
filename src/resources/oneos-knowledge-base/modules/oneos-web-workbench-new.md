## 起点 → 运作 → 闭环

- **起点**：每日开工进入工作台
- **怎么运作**：见下方操作说明与正向步骤。
- **闭环**：异常与待办跳转源模块并完成业务闭环

## 前置条件

- 用户已登录并具备角色视角

## 操作说明（主路径）

1. 扫视预警 KPI
2. 处理待办/审批
3. 快捷跳转业务模块办结
4. 查看通知

## 业务规则

- 工作台不替代源模块闭环
- 角色视角切换
- 催办为演示能力时需标明

## 正向 / 逆向

**正向**（摘要同上操作说明）

**逆向 / 边界**

| 情况 | 系统表现 |
|------|----------|
| 模块已下线 | 勿再验收/入口移除 |
| 无待办 | 空态 |

## 禁止与边界
