# 安全管理条线

**闭环一句话**：司机档案与培训证据链 → 安全资料学习 → 违章/事故定责与保险 → 责任费用进入还车应结会签。

## 责任部门

安全部（主）；还车会签联动业管/运维/能源/财务。

## 标准步骤

1. 司机管理与证照。
2. 内部培训与证据链；安全资料库移动端学习。
3. 违规违章（分值/罚款/逾期代处理费）。
4. 事故定责、保险理赔与保费上浮。
5. 费用归集至还车应结。
