# 预付余额变更明细 · 排序与行余额规则（给开发 / Codex）

> 模块：加氢站管理 → 站点信息 → 预付余额 → 余额变更明细  
> 目标：列表主余额正确时，明细「锚点之上」从锚点余额连续滚动；加氢递减、充值回升；日精度 `00:00:00` 不搅乱切线。

---

## 1. 术语

| 词 | 含义 |
|---|---|
| 锚点 | 类型 =「期末余额」的配置行；余额列 = 配置值；变动金额为空 |
| 发生额行 | 车辆加氢、氢气充值等会改余额的流水 |
| 生效时间 | 用于切线与排序的时间（见 §3） |
| 开累段 | 生效时间 **严格晚于** 最近有效锚点 T 的发生额集合 |
| signedAmount | 加氢 &lt; 0；充值 &gt; 0；其它收支按符号 |

---

## 2. 一条总规则

```text
最近锚点余额为起点；
仅「生效时间 > T」的发生额进入开累段；
开累段按（生效时间升序, 单据号升序）正序累计行余额；
列表按同一顺序倒序展示（新在上）；
加氢与充值同一时间轴混排，禁止按类型分堆；
打开明细禁止回写列表预付余额。
```

**四处必须相等：** 站点列表预付余额 = 明细顶栏当前余额 = 开累段滚到最新一笔的行余额 = `锚点余额 + Σ signedAmount(开累段)`。

---

## 3. 生效时间

| 记录 | 生效时间 |
|---|---|
| 精确时分秒流水 | 原时间戳 |
| 日精度流水（加氢/充值时间为当天 `00:00:00`，或标记「仅到日」） | 归入该业务日；与日末锚点比时：该日整日 ∈ 锚点日及更早侧；**下一业务日**起才入开累段。过渡实现：比较键 = 当日 `23:59:59.999` |
| 期末余额锚点 | 推荐配置为 **业务日 · 日末**；若仍存时分秒，则 T = 该时间戳 |

同秒 / 同比较键：发生额 **不入** 开累段（`>` 才进，`≤` 在锚点下）。

---

## 4. 排序键

升序键（旧→新）：

```text
(effectiveTime ASC, docNo ASC)
```

- `docNo`：单据号；无则用入库主键。  
- **禁止**「充值优先 / 加氢优先」作为次关键字。  
- 锚点行本身不参与开累段排序；展示时插在「开累段倒序」与「锚点前历史倒序」之间。

列表最终从上到下：

```text
[开累段倒序] → [锚点行] → [生效时间 ≤ T 的历史倒序]
```

---

## 5. 行余额算法

```text
bal[0] = 锚点.余额
将开累段按 §4 升序排成 tx[1..n]
bal[i] = bal[i-1] + signedAmount(tx[i])
展示时开累段第 k 行（从上往下第 k 条，对应 tx[n-k+1]）的余额列 = bal[n-k+1]
```

- 紧邻锚点 **上一行** = `tx[1]`，余额 = `bal[1]`。  
- 纯加氢：从锚点往上看呈 4.9万 → 4.8万 → 4.7万。  
- 穿插充值：该行余额回升，其后继续代数滚。  
- **禁止**按屏幕从上往下累加。

---

## 6. 符号与展示

| 类型 | signedAmount | 变动金额展示 |
|---|---|---|
| 期末余额 | — | `—` / 空 |
| 车辆加氢 | 负 | 支出样式 |
| 氢气充值 | 正 | 收入样式（如 +） |
| 日精度 | 同上 | 时间旁可注「仅到日」 |

---

## 7. 例子

锚点 = 50000；开累段早→晚：加氢 −1000，充值 +3000，加氢 −1000。

```text
正序 bal: 49000 → 52000 → 51000

展示（上→下）:
  51000  加氢
  52000  充值
  49000  加氢
  50000  期末余额锚点
  …      更旧历史
```

---

## 8. 验收（Codex / QA）

- [ ] 锚点之上仅 `effectiveTime > T`；同秒发生额在锚点下  
- [ ] 行余额由 §5 正序累计再倒序展示，非屏幕方向累加  
- [ ] 加氢/充值混排同一轴；同秒只比单据号  
- [ ] 纯扣减：锚点上方向上递减；有充值允许回升  
- [ ] 日精度不导致开累段余额跳到无关大数  
- [ ] 列表 = 顶栏 = 最新开累行余额；打开明细不回写列表  

---

## 9. 不做

- 不按类型分堆排序  
- 不因本缺陷重算列表主公式（除非对账证明列表错）  
- 本规则不强制本迭代补全上报时分秒
