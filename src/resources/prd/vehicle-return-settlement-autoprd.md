## 1. 一句话与目标

**一句话**  
还车应结款台账按多部门会签督办（提交人+状态），详情按《各车型收费方案》自动核算无忧包，运维可办理费用/减免并转交办理人，安全违章事故按本段自动带出。

**目标**
1. 台账「提交情况」为合并表头四组（安全/业务服务/运维/能源），展示提交人+提交状态（图标语义）。
2. 车型费率统一：养护保按里程、易损保按月费；是否购买由业管与客户谈妥反写。
3. 运维无忧包减免挂钩购买状态；运维办理人可转交（原因必填），不改费用与审批流。
4. 安全板块本段违章/事故自动带出；页头无条线面包屑。

**非目标**
- 不在本单手工改无忧包单价
- 不改造轮胎保费率表
- 不改审批流节点结构；本期不做收付款关联/归档演示（业财门禁另迭代）
- 不新增违章事故录入页

## 2. 用户与角色

| 角色 | 职责 |
|---|---|
| 业管 | 督办台账；只读安全与自动核算；可代转运维办理人 |
| 运维 | 填费用与无忧包减免；提交/撤回运维组；转交办理人 |
| 安全员 | 填写/提交安全费用；不阻断违章事故自动展示 |
| 能源 / 业务服务 | 各部门费用段办理（演示） |

---

## 3. 用户故事（起点 → 运作 → 闭环）

### US-1 台账三视角督办（5）
- **起点**：进入还车应结款台账，切换列表 / 看板 / 主从。
- **怎么运作**：KPI、Pill Tabs、搜索 + 更多筛选（查询/重置后收起）；「提交情况」合并四组子列，每格显示提交人+状态；养护保/易损保是/否；操作：查看；待提交/撤回/驳回可费用明细；待审批/审批中可撤回。
- **闭环**：定位目标单据并进入详情。

### US-2 无忧包自动核算（8）
- **起点**：打开费用明细；单据已带出车型、本段里程、交还车时间、是否购买。
- **怎么运作**：养护保＝里程×元/公里；易损保＝计费月数×月费；未购买不计费且不生成费用行。
- **闭环**：业管核对核算式与金额。

### US-3 运维无忧包减免（5）
- **起点**：预览角色切运维，运维组待提交且审批未进入待审批后。
- **怎么运作**：已购对应包项可填减免；净计入汇总；审批中费用只读。
- **闭环**：暂存/提交运维组。

### US-4 安全板块自动展示违章事故（5）
- **起点**：单据已生成，业管打开详情。
- **怎么运作**：按本段交还车周期只读带出；空态「暂无违章记录」/「暂无事故记录」。
- **闭环**：业管判断客户未处理事项。

### US-5 运维办理人转交（5）
- **起点**：运维或业管（代转）打开费用明细，审批状态≠审批完成。
- **怎么运作**：选运维办理人、填原因（必填）；拦截转给自己/非运维；只换办理人不改费用与审批流；审批中仍可转交。
- **闭环**：办理人更新，转交记录可见。

---

## 4. 关键规则

1. 收费标准以《各车型收费方案》终版为准。
2. 是否购买由业管与客户谈妥反写；系统只根据是否购买自动核算。
3. 计费月数＝交还车间隔天数/30 向上取整，有租期至少 1 月。
4. 无忧包减免计入业务成本；未购对应包时减免禁用。
5. 安全违章/事故时间窗：实际交车日～实际还车日。
6. 转交只换办理人；原因空不可提交；审批完成后无转交入口。
7. 审批状态：待提交=四组未齐且未交审批；待审批/审批中/完成定义对齐现网需求说明。

---

## 5. 正向 / 逆向

**正向**
1. 双包已购 → 自动核算 + 业务费用行 → 待结算含包费。
2. 运维可填减免 → 净额回写；可转交给其他运维。
3. 安全未提交时仍可见本段违章/事故或空态。

**逆向**
| 情况 | 期望 |
|---|---|
| 未购买无忧包 | 核算 0；无业务费用行；减免禁用 |
| 车型不在方案表 | 提示未配置，费用 0 |
| 本段无违章/事故 | 对应空态文案 |
| 转给自己或原因空 | 拦截 |
| 审批完成 | 无转交；费用只读 |
| 待审批/审批中 | 无费用明细入口；可撤回 |

---

## 6. 验收重点

1. 详情扁平页头：返回 + 20px 标题 + 单号紫胶囊；**无**条线面包屑。
2. 台账提交情况为合并四组子列，显示人+状态。
3. `HC-JS-2026-001` 双包核算与运维减免；可转交办理人。
4. `HC-JS-2026-002` 双包未购：核算 0、减免禁用。
5. `HC-JS-2026-004` 仅易损保：维修可减免、保养减免禁用。
6. 审批中单据操作列无「费用明细」、有「撤回」。
7. 车牌无间隔点 `·`；查询/重置收起更多筛选。
