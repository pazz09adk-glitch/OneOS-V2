## 1. 一句话与目标

**一句话**  
还车应结款按《各车型收费方案》自动核算保养无忧包（养护保）、维修无忧包（易损保）；是否购买由业管与客户谈妥反写，系统只按购买结果计费，并联动运维无忧包减免。

**目标**
1. 车型费率统一：养护保按里程单价、易损保按月费，与收费方案终版一致。
2. 业管谈妥是否购买后，费用自动进业务服务组并计入待结算；未购买不计费。
3. 运维对未结算保养/维修/轮胎磨损可填无忧包减免；未购对应包时减免禁用。
4. 保留安全板块本段违章/事故自动带出与台账三视角。

**非目标**
- 不在本单由业管手工改无忧包单价（改费率走收费方案主数据）
- 不改造轮胎保费率表（仅保留减免开关）
- 不改会签/审批流节点
- 不新增违章事故录入页

| 角色 | 职责 |
|---|---|
| 业管 | 与客户谈妥是否购买无忧包（反写是/否）；台账督办；只读看安全与自动核算结果 |
| 运维 | 填写运维费用与无忧包减免；提交运维组 |

## 3. 用户故事（起点 → 运作 → 闭环）

### US-1 台账三视角督办（5）
- **起点**：进入还车应结款台账，切换列表 / 看板 / 主从。
- **怎么运作**：KPI、Pill Tabs、搜索 + 更多筛选（查询/重置后收起）；列表展示养护保/易损保是否购买；操作「查看 / 费用明细」。
- **闭环**：定位目标单据并进入详情。

### US-2 无忧包自动核算（8）
- **起点**：打开费用明细；单据已带出车型、本段里程、交还车时间、是否购买养护保/易损保。
- **怎么运作**：系统按收费方案：养护保＝里程×元/公里；易损保＝计费月数×月费（不含轮胎、漆面、玻璃）；未购买显示 0 且业务服务组不生成对应费用行；已购买则自动写入业务服务组费用项并参与待结算。
- **闭环**：业管核对核算式与金额；无需手工改价。

### US-3 运维无忧包减免（5）
- **起点**：预览角色切运维，运维组待提交。
- **怎么运作**：对未结算保养费（需养护保）、未结算维修费（需易损保）、轮胎磨损费（需轮胎保）可填减免；未购则输入禁用；净计入＝金额−减免，待结算按净额汇总。
- **闭环**：暂存/提交运维组，KPI 待结算同步。

### US-4 安全板块自动展示违章事故（5）
- **起点**：单据已生成，业管打开详情。
- **怎么运作**：安全板块按本段交还车周期只读带出违章/事故；空态「暂无违章记录」。
- **闭环**：业管判断客户未处理事项。

---

## 4. 关键规则

1. 收费标准以《各车型收费方案》终版为准（苏龙/宇通/飞驰/现代/楚风等车型）。
2. 是否购买由业管与客户谈妥反写；系统只根据是否购买自动核算，不替代商务洽谈。
3. 计费月数＝交还车日期间隔天数/30 向上取整，有租期时至少 1 月。
4. 无忧包减免不列入运维成本，计入业务成本；未购对应包时减免禁用。
5. 安全违章/事故时间窗：实际交车日～实际还车日；租期外历史不展示。

---

## 5. 正向 / 逆向

**正向**
1. 已购养护保+易损保 → 详情见自动核算卡片与业务服务组费用行 → 待结算含包费。
2. 运维已购包项可填减免 → 净额回写待结算。
3. 安全未提交时业管仍可见本段违章/事故或空态文案。

**逆向**
| 情况 | 期望 |
|---|---|
| 未购买无忧包 | 核算为 0；不生成业务费用行；对应减免禁用 |
| 车型不在方案表 | 提示未配置费率，费用为 0 |
| 本段无违章事故 | 暂无违章记录 |
| 运维已提交 | 费用与减免只读，可撤回后再改 |
