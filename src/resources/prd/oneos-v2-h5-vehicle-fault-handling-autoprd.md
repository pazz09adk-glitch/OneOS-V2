# 故障处置（H5）· AutoPRD

## 1. 一句话

外勤/App 场景下查看与跟进车辆故障，支持列表卡片、看板管道与处置工作台，业务口径与 PC 故障处置一致。

## 2. 双入口

- H5：本原型（390/375 视口模拟 + 深浅色）
- PC：`/prototypes/vehicle-fault-handling`

## 3. 用户故事（摘要）

1. **卡片台账**：KPI 深链 + 搜索 + Bottom Sheet 筛选定位单据。  
2. **看板跟进**：横向 Tab 切换四阶段管道。  
3. **处置台**：查看描述/AI 摘要/证据与留痕，吸底执行处置/挂起/催办。

## 4. 验收

侧栏单项；三视角与底栏映射；触控 ≥44px；车牌无中圈点；处置时限/挂起/催办与 PC 对齐（已挂起不计时限）。
