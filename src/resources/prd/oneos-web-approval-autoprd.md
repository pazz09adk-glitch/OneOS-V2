# 审批中心 (OneOS V2) · AutoPRD

> **模块位置**：审批中心原型  
> **更新时间**：2026-07-28  
> **核心变更**：1 页 4 Tab + 主从；**通用详情骨架**；业务字段只来自现成样例；标题与审批流编号套用新规范。

---

## 1. 一句话与目标

**一句话**  
统一办理、发起、已办与抄送的审批中心：左卡扫读、右详通用壳，不按业务造专属页、不造业务数据。

**本期目标**  
1. 1 页 4 Tab + 徽标 + 主从 Split；  
2. 详情固定通用骨架（页头 → 风险可选 → 申请信息 → 附件可选 → 审批流 → 底栏）；  
3. 标题/审批流编号新规范；样例事实原样迁移。

**非目标**  
- 不为演示新增无样例来源的单据或字段；  
- 不迁入保险/账单等业务专属详情结构；  
- 不发明未核对现网的转交/加签等底栏按钮。

---

## 2. 模块边界

| 子域 | 做什么 | 不做什么 |
|------|--------|----------|

## 3. 用户与角色

| 角色 | 主要目标 |
|------|----------|
| 审批人 | 在待办办理通过/终止/评论 |
| 发起人 | 追踪进度、必要时撤回 |
| 被抄送人 | 查阅知会单据 |

---

## 4. 用户故事

### US-01 办理待办
- **起点**：打开审批中心默认待办；  
- **怎么运作**：选左卡 → 右详 → 底栏「通过 / 终止 / 评论」并填弹窗；  
- **闭环**：进入已办，待办徽标递减；评论写入审批流。

### US-02 追溯发起
- **起点**：切「我发起的」；  
- **怎么运作**：查看样例单据与当前审批角色；审批中可撤销申请；  
- **闭环**：确认进度或撤回成功。

### US-03 多业务同壳
- **起点**：切换不同业务类型样例；  
- **怎么运作**：壳层区块标题不变，仅 KV/节点随样例变；  
- **闭环**：多业务切换体验一致。

## 5. 标题与编号 + 通用骨架

| 字段 | 规则 | 列表 | 详情 |
|------|------|------|------|
| 审批流编号 | `AP-{码}-{YYYYMM}-{流水}` | 不展示（可搜） | 「审批流编号」+ 紫胶囊 + 复制 |
| 业务单据号 | 样例原号 | 不展示（可搜） | 仅申请信息 |
| 主/副标题 | 主体+标的+动作 / 项目·约束 | — | 页头 |
| typeLabel | 定版短名 | 入合成标题 | Tag |
| 列表标题 | `{发起人}提交的{短类型}-{短摘要}` | 展示 | — |

**详情骨架顺序**：页头 → 风险提示（可选）→ 申请信息（关键摘要 + 可折叠分组）→ 明细表（可选）→ 附件（可选）→ 审批流（垂直·完整定义链，含未到达节点）→ 底栏。

租赁合同等：摘要保留列表四项；合同查看字段按「费用汇总 / 合同信息 / 客户信息」分组折叠，默认只展开费用与合同，避免字段墙。

**允许改写**：id / title / subtitle / typeLabel / 「审批流编号」展示名。  
样例账号：现网 `yaoshoutao` / 姚守涛；待办现网 0 条时原型可留 1 条真实字段待办验收弹窗；抄送空。底栏对齐：通过/终止/评论；发起侧撤销申请/评论。

**禁止改写**：金额、数量、风险、意见、附件、审批人、时间等事实。

---

## 6. 正向 / 逆向

**正向**：检索命中 → 左卡选中 → 详情核对 → 办理闭环。  

**逆向**

| 情况 | 表现 |
|------|------|
| 无选中 | 空态提示从左侧点选 |
| 样例无附件/风险 | 对应区块不出现 |
| 已结案待办 | 不展示通过/终止/评论底栏 |
