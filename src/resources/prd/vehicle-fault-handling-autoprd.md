# 故障处置（PC）· AutoPRD

## 1. 一句话

运维专员在桌面端管理车辆故障台账，按上报后 30 天处置时限推进处置、挂起、催办与证据链归档闭环；已挂起不计剩余时限。

## 2. 双入口

- PC：故障处置台账（列表 / 看板 / 主从）
- H5：故障处置移动端（独立原型，App/小程序嵌套）

## 3. 用户故事（摘要）

1. **台账检索**：从 KPI / 状态 Pill / 高阶筛选定位单据。  
2. **看板推进**：在待处理→处理中→挂起→归档管道查看进度。  
3. **主从处置**：左侧选单、右侧工作台完成处置/挂起/催办。  
4. **归档闭环**：附件与地点齐备后在处置全页归档；否则拦截并提示。  
5. **查看 / 处置**：同原型内全页打开（非抽屉）；详情为左主（上下文/描述·AI/证据）+ 右 340px 催办督办留痕，返回台账。

## 4. 验收

三视角可用；列表等级/解决/任务状态为正文（仅告警色强调）；处置时限为辅文非标签（已挂起为「挂起、暂停中」、不进临期逾期）；查看/处置全页且详情铺满（左主+右留痕）；归档硬门槛；与 H5 业务口径一致。
